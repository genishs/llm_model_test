## 원본 · GGUF 출처

- 베이스: [c7](c7.md) 과 같은 파일 (원본 https://huggingface.co/Qwen/Qwen2.5-Coder-7B-Instruct)
- 어댑터: **비공개**. 공개 링크가 없으며 파일도 이 레포에 없다. 「직접 학습한 LoRA 를 붙이는 예시」로만 둔다.

## 구조

dense 7B(활성 = 전체) + LoRA 어댑터. 어댑터는 qkvo + MLP 층, rank 16, RTX 4060 에서 학습했고 React 컴포넌트 코드 생성에 맞췄다(자체 held-out 평가 95%, 7B 어댑터 중 1위).

## 서버 설정 (router preset)

공통값: `n-gpu-layers = 999`(전부 GPU) · `flash-attn = on` · `jinja = true` · `c = 65536`(문맥 64K) · `load-mode = none`(통째로 메모리에 올림). 모델 섹션이 같은 키를 쓰면 공통값을 덮어쓴다.

- 생각 모드: 없음
- 샘플링: 모델 기본값
- 투기적 디코딩: 없음
- 문맥: `c = 32768`
- LoRA: `lora = <어댑터 경로>` 한 줄. 자기 어댑터 경로로 바꿔 쓰면 된다.
- mmproj: 없음

## 알려진 특성 · 주의점

- LoRA 를 붙여도 속도는 `c7` 과 비슷하다(생성 28.9 -> 27.8 t/s).
- 어댑터가 공개되지 않았으므로 같은 결과를 재현할 수 없다. 이 항목은 LoRA 를 붙이는 방법의 예시다.
