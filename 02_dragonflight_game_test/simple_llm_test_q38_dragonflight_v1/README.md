# Dragon Flight

웹 브라우저에서 바로 실행되는 HTML5 캔버스 기반 세로 스크롤 슈팅 게임입니다.
모바일 게임 "드래곤플라이트"의 게임성(자동 공격 · 용 캐릭터 · 코인/아이템 수급 · 보스)을 참고하되, 모든 그래픽은 캔버스 API로 직접 그린 것이며 사운드는 WebAudio로 합성한 것입니다. 원작의 어떤 에셋도 사용하지 않습니다.

## 실행 방법

별도 설치·빌드·서버가 필요 없습니다.

```
index.html 파일을 브라우저로 더블클릭(열기)하면 됩니다.
```

- Chrome / Edge / Firefox / Safari 등 최신 브라우저 권장
- 모바일/태블릿의 브라우저에서도 터치로 플레이 가능
- 인터넷 연결 불필요 (완전 오프라인 동작)

## 조작법

| 입력 | 동작 |
|---|---|
| `←` / `→` 또는 `A` / `D` | 용 좌우 이동 |
| 마우스 / 터치 | 포인터 위치를 따라 이동 |
| 클릭 / `Enter` / `Space` | 시작 · 재시작 |

- 공격은 **자동 발사**됩니다. 이동에만 집중하면 됩니다.

## 게임 규칙

- 플레이어(용)는 화면 아래에서 좌우 이동만 하며 총은 자동으로 쏩니다.
- 적 용은 **가로 한 줄 단위 웨이브**로 위에서 내려옵니다. 적마다 체력이 있어 피격 시 줄고 0이 되면 쓰러집니다.
- **적 몸체에 닿으면 피해를 입습니다** (체력 3, 소진 시 게임 오버).
- 쓰러진 적은 **코인**을 떨어뜨리고, 확률적으로 **아이템**이 나옵니다:
  - `P` 공격 강화 (파워 1~3단계, 최대 3연사)
  - `M` 자석 (코인 자동 흡입 8초)
  - `S` 방어막 (다음 1회 피격 무효, 6초)
  - `+` 체력 회복
- **운석**은 떨어지기 전 해당 세로 줄에 `!` 경고를 먼저 표시합니다.
- 일정 거리마다 **보스**가 등장하며, 처치 시 레벨업(속도·적 체력 상승).
- 점수 = 비행 거리 + 처치 보너스 + 코인 + 보스 처치.
- 진행할수록 스크롤 속도·적 체력·탄막이 어려워집니다.

## 파일 구성

```
simple_llm_test_q38_dragonflight_v1/
├── index.html      # 캔버스 + 레이아웃 (게임 진입점)
├── dragonflight.js # 게임 엔진: 상태·입력·플레이어·웨이브·보스·점수·렌더링
├── effects.js      # WebAudio 사운드 엔진 (합성 음향, 에셋 없음)
└── README.md       # 이 문서
```

## 기술 요약

- 순수 vanilla JavaScript (외부 라이브러리 0)
- 로직 해상도 420×740을 CSS/DPR 스케일링으로 어떤 화면에든 맞춰 표시
- `requestAnimationFrame` 고정 스텝 업데이트
- 사운드: WebAudio 오실레이터/노이즈 합성 (파일 없음)
