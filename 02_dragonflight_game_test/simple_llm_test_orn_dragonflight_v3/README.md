# Dragonflight - 용의 격투

브라우저에서 바로 실행되는 세로 스크롤 슈팅 게임. 용(플레이어)가 좌우로 이동하며
위에서 내려오는 적 용 웨이브를 자동으로 발사되는 공격으로 물립니다.

원작 모바일 게임의 게임성을 참고했으나, 그래픽·소리·이름은 처음부터 직접 제작한
원작 비복제 오리지널 에셋으로 구현했습니다.

## 게임 규칙

- **플레이어(용)**는 화면 아래에서 좌우로만 이동하며, 공격은 자동으로 계속 발사됩니다.
- **적(용)**는 가로 한 줄(레인) 단위의 웨이브에서 내려옵니다.
  - 적마다 체력이 있어 맞으면 줄어들고 0이 되면 쓰러집니다.
  - 적에 닿으면 게임 오버입니다.
- 쓰러진 적은 **코인**을 떨어뜨리고, 가끔 **아이템**을 떨어뜨립니다:
  - **공격 강화**(▲): 데미지 증가 + 탄막 추가 + 발사 속도 향상
  - **코인 자석**(M): 가까운 코인을 끌어모음
  - **방어막**(◈): 일정 시간 피격 무적
- **운석**이 떨어지기 전에는 해당 레인에 경고를 먼저 표시합니다.
- 일정 거리마다 **보스**가 등장합니다 (체력바 표시).
- **점수·거리·처치 수·코인**으로 평가되며, 진행할수록 속도와 적 체력이 올라갑니다.
- 플레이어는 총 5개의 체력(HP)을 가지며, 피격당하면 줄어들고 0이 되면 게임 오버.
  (아이템으로 획득한 방어막은 피격 무적으로 대체됩니다.)

## 스테이지 (LEVEL)

- 게임은 **스테이지** 단위로 진행되며, HUD 상단에 현재 스테이지가 표시됩니다.
- 각 스테이지의 일정 거리에 **보스**가 등장합니다. 보스를 쓰러뜨리면 **다음 스테이지**로 넘어갑니다.
- 스테이지가 오를수록 보스의 체력·속도·탄도가 높아지고, 일반 적의 체력·속도도 증가하여 어려워집니다.
- 보스를 처치하면 자동으로 다음 스테이지로 이어지며 점수가 추가로 부여됩니다.

## 크레딧 & 컨티뉴 (ARCADE 개념)

- **크레딧**은 게임을 시작·계속할 수 있게 하는 아케이드 통화입니다. HUD 상단에 남은 크레딧이 표시됩니다.
- **크레딧 주입 (Insert Coin)**:
  - PC: 키보드 **`I`** 키를 누르면 크레딧 +1.
  - 모바일: 화면 **상단 중앙을 탭**하면 크레딧 +1.
- 게임 중 수집하는 **코인**과 다릅니다. 코인은 처치한 적/보스에서 떨어뜨리는 플레이용 코인이고,
  코인 10개당 **크레딧 1**이 자동 적립됩니다. (화면에서 '코인'과 'CREDIT'는 별개의 항목으로 표시됩니다.)
- **시작**: 크레딧이 1 이상 있어야 「게임 시작」 버튼으로 시작할 수 있습니다.
- **컨티뉴**: 게임 오버가 되면 **15초 카운트다운**과 함께 계속하기 화면이 나옵니다.
  시간 안에 「계속하기」를 눌러 크레딧 1을 쓰면 **점수·스테이지를 그대로 유지**한 채 이어서 할 수 있습니다.
  시간 안에 이어하지 않으면 **타틀 화면(대기)**으로 돌아갑니다. 크레딧이 없으면 '계속하기' 버튼이 비활성화됩니다.

## 실행 방법

설치·빌드·서버 필요 없습니다.

1. 이 폴더의 `index.html` 을 더블클릭하거나,
2. 어떤 브라우저(Chrome, Edge, Firefox, Safari)로여도 바로 실행됩니다.

 필요한 파일은 `index.html`, `style.css`, `game.js` 세 개뿐입니다.

## 조작법

| 동작 | 키보드 | 마우스 | 터치 |
|------|--------|--------|------|
| 이동 | `←` / `→` (또는 `A` / `D`) | 커서 방향으로 이동 | 손가락을 끌어 이동 |
| 공격 | 자동 발사 | 자동 발사 | 자동 발사 |
| 크레딧 주입 | `I` 키 | — | 화면 상단 중앙 탭 |

- 키보드와 마우스/터치 모두 지원하며, 마우스로 이동 시 해당 레인으로 부드럽게 움직입니다.
- **모바일 터치 조작**: 화면에 손가락을 대고 좌우로 끌어(drag) 해당 위치로 이동합니다.
  손가락을 놓으면 현재 위치에 멈춥니다. 좌우 이동 외에도 화면을 터치하기만 빠르게 이동할 수 있습니다.
- 터치 시 화면 스크롤/줌이 방지되어 부드럽게 조작할 수 있습니다.
- 크레딧 주입은 이동과 분리되어 있습니다: 상단 중앙을 가볍게 탭하면 주입되고, 그 아래를 끌어 이동합니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 게임 화면·HUD·시작/게임오버/계속 화면 구조 |
| `style.css` | UI 스타일(HUD, 버튼, 스크린, 카운트다운) |
| `game.js` | 게임 로직 전체(엔티티, 물리, 스코어, 보스, 스테이지, 크레딧, 컨티뉴) |

## 게임 흐름

1. **대기 화면(타틀)**에서 크레딧이 1 이상이면 「게임 시작」, 아니면 `I` 키/화면 상단 탭으로 크레딧 주입.
2. 적이 웨이브로 떨어지므로 좌우로 피하면서 자동으로 발사된 공격으로 처치.
3. 코인과 아이템을 수집해 공격력을 높여보세요. 코인 10개당 크레딧이 쌓입니다.
4. 일정 거리마다 등장하는 보스를 물리면 다음 스테이지로 진행됩니다.
5. 적·적탄·운석에 닿거나 HP가 0이 되면 **게임 오버** → 15초 카운트다운과 함께 **계속하기** 화면.
6. 「계속하기」로 크레딧 1을 쓰면 점수·스테이지 유지한 채 재개, 시간 안에 하지 않으면 **대기 화면**으로 복귀.
