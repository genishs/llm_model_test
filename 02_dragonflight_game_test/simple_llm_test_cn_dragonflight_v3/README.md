# DragonFlight - 세로 스크롤 슈팅 게임

## 🐉 게임 소개

**DragonFlight**는 모바일 게임「드래곤플라이트」의 게임성을 참고하여 직접 제작한 웹 기반 세로 스크롤 슈팅 게임입니다.

- **플레이어(용)**: 자동 발사와 함께 좌우 이동으로 적을 물리칩니다
- **적(용)**: 웨이브 단위로 내려오며 체력이 있습니다
- **운석**: 경고 후 떨어지는 위협적인 장애물
- **보스**: 스테이지마다 등장하는 강력한 적
- **코인 & 아이템**: 처치 보상으로 획득 가능

## 📱 게임 방식 (아케이드 스타일)

### 크레딧 시스템
- **크레딧**: 코인을 넣어 게임을 시작할 수 있는 권한을 획득합니다
- **코인 삽입**: 키보드 스페이스바 또는 화면의 코인 버튼 클릭으로 크레딧 추가
- **게임 시작**: 최소 1개의 크레딧이 있어야 게임을 시작할 수 있습니다

### 스테이지 시스템
- **스테이지 진행**: 보스를 처치하면 다음 스테이지로 이동합니다
- **난이도 증가**: 스테이지가 오를수록 적의 속도와 체력이 증가합니다
- **웨이브**: 스테이지 내에서 5개의 웨이브를 클리어하면 보스 등장
- **보스**: 각 스테이지의 마지막 웨이브(5웨이브)에 등장하는 강력한 적

### 컨티뉴 시스템
- **게임 오버**: 플레이어가 적이나 운석에 닿으면 게임 오버
- **컨티뉴 화면**: 게임 오버 후 10초 동안 컨티뉴 기회 제공
- **컨티뉴 사용**: 1개의 크레딧을 사용하여 점수·스테이지·획득 코인을 유지하고 이어하기
- **컨티뉴 실패**: 시간이 종료되면 타이틀 화면으로 돌아갑니다

## 📱 모바일 터치 조작

**터치 조작 방법**:
1. 화면을 터치
2. 손가락을 좌우로 드래그
3. 용이 손가락 이동에 따라 따라움직임
4. 손가락을 떼면 이동 멈춤

**모바일 최적화**:
- 반응형 디자인으로 화면 크기에 자동 조절
- HUD 요소 크기 자동 조정
- 부드러운 터치 조작 지원

## 🚀 실행 방법

### 브라우저로 바로 실행

1. `index.html` 파일을 브라우저(Chrome, Edge, Safari 등)로 열기
2. 타이틀 화면에서 코인을 넣어 크레딧 확보
3. 게임 시작 버튼 클릭
4. 조작하여 게임 진행

### 요구 사항

- 최신 웹 브라우저
- 인터넷 연결 불필요 (로컬 파일로 실행 가능)

## 🎮 조작법

### 키보드
- **← / → 화살표**: 좌우 이동
- **Space**: 코인 삽입 (크레딧 추가)
- **자동 발사**: 지속적으로 적 향해 포탄 발사

### 마우스
- **클릭 후 드래그**: 용이 마우스 위치로 부드럽게 이동
- **좌클릭**: 코인 삽입 버튼 클릭

### 터치(모바일/스마트폰)
- **손가락으로 끌기**: 화면을 터치하고 좌우로 드래그하여 용 이동
- **터치 버튼**: 화면의 코인 버튼 터치로 코인 삽입
- **자동 발사**: 지속적으로 적 향해 포탄 발사
- **터치 동작**:
  1. 화면을 터치
  2. 손가락을 좌우로 드래그
  3. 용이 손가락의 이동 방향으로 따라움직임
  4. 손가락을 떼면 이동 멈춤

## 🎯 게임 규칙

### 기본 메커니즘
- **점수**: 날아간 거리 + 적 처치 보상
- **거리**: 게임 진행 시 자동 증가 (최대 5000m)
- **코인**: 적 처치 시 획득 (10코인/적)
- **크레딧**: 게임 시작을 위한 시스템 코인 (게임 내 코인과 별도)

### 스테이지 규칙
| 스테이지 | 웨이브 | 보스 등장 | 난이도 |
|---------|--------|----------|--------|
| 1 | 1-5 | 웨이브 5 | 기본 |
| 2 | 1-5 | 웨이브 5 | +10% |
| 3 | 1-5 | 웨이브 5 | +20% |
| ... | ... | ... | 증가 |

- **웨이브 클리어 조건**: 모든 적 처치
- **보스 클리어 조건**: 보스 체력 0
- **보스 보상**: 100코인 + 1000점
- **스테이지 업**: 보스 클리어 시 자동 이동

### 아이템
| 아이템 | 효과 | 표시 |
|--------|------|------|
| **W (Weapon)** | 무기 레벨 업 (1~3단계) | 빨간색 |
| **S (Shield)** | 10초간 무적 방어막 | 파란색 |
| **M (Magnet)** | 10초간 아이템/코인 자동 흡수 | 노란색 |

### 적의 종류
1. **일반 적**: 체력 2~3, 하단에서 내려옴
2. **운석**: 경고 후 떨어짐, 닿으면 게임 오버
3. **보스**: 스테이지마다 등장, 강력한 공격

### 난이도 조절
- **wave 수 증가**: 적 속도와 체력 증가
- **웨이브 수**: wave/5 단위로 적 수 증가
- **스테이지 증가**: 전체적인 난이도 상승

## 🎨 그래픽
