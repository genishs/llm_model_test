# Dragonflight (세로 스크롤 슈팅 · 아케이드)

웹 브라우저에서 바로 실행되는 HTML5 Canvas 기반 세로 스크롤 슈팅 게임입니다.
모바일 게임 「드래곤플라이트」의 게임성을 참고했으나, 모든 그래픽은 Canvas로 직접 그려
원작의 이미지·소리·이름 에셋은 사용하지 않았습니다.

아케이드 게임처럼 **스테이지(레벨)**, **크레딧(코인 투입)**, **컨티뉴** 개념을 도입했습니다.

## 실행 방법

설치·빌드·서버가 필요 없습니다. 아래 두 가지 중 하나로 열면 바로 실행됩니다.

- `index.html` 파일을 브라우저(Chrome, Edge, Firefox 등)로 더블클릭하여 열기
- 또는 이 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속 (선택)

## 게임 흐름

```
타이틀(대기) → [크레딧 코인 투입] → 시작 → 플레이 → 게임 오버 → 컨티뉴 화면(카운트다운)
      ↑                                                          ├─ 크레딧 있으면 이어서 진행
      └──────────── 시간 내 미연결 시 타이틀로 반환 ────────────┘
```

- 끊김 없이 하나의 흐름으로 이어집니다. 새로고침·새 로딩이 없습니다.

## 스테이지 (Stage) 규칙

- HUD 좌측에 현재 **STAGE**가 표시됩니다. 시작 시 중앙에 "STAGE n" 배너가 나타납니다.
- 각 스테이지는 일정 시간 적 웨이브를 격파한 뒤 **보스 용**이 등장합니다.
- **보스를 쓰러뜨리면 다음 스테이지로 넘어갑니다.** (점수·코인·처치 수 유지)
- 스테이지가 오를수록 어려워집니다:
  - 적 기본 체력 증가 (`1 + (스테이지-1)`)
  - 적 하강 속도·웨이브 밀도(열 개수) 증가
  - 보스 체력·속도 증가, 운석 낙하 빈도·속도 증가
  - 배경 스크롤 속도 증가
- 보스 격파 점수는 스테이지에 비례해 커집니다 (`500 × 스테이지`).

## 크레딧 (Credit) — 코인 투입

- **크레딧 코인**은 게임 안에서 줍는 코인(COIN)과 완전히 별개입니다.
  - `CREDIT` = 게임을 시작/컨티뉴하기 위해 넣는 아케이드 화폐
  - `COIN`   = 플레이 중 적을 쓰러뜨려 얻는 점수용 코인 (HUD에 각각 따로 표시)
- **크레딧이 있어야 게임을 시작할 수 있습니다.** 타이틀·컨티뉴 화면에 남은 크레딧이 표시됩니다.
- 크레딧 투입 방법:
  - 키보드: `C` 키
  - 터치/마우스: 화면의 **「코인 넣기 (C)」** 버튼 탭, 또는 타이틀 화면 빈 곳 탭
- 코인을 넣으면 `START` / `CONTINUE` 버튼이 활성화되고, 시작·컨티뉴 시 크레딧 1을 소모합니다.

## 컨티뉴 (Continue)

- 게임 오버가 되면 잠시 **GAME OVER** 화면 후 **CONTINUE?** 카운트다운 화면으로 전환됩니다.
- 카운트다운(기본 10초) 동안 크레딧을 넣어 **크레딧으로 계속하기**를 누르면
  **점수·스테이지를 유지한 채** 이어서 플레이합니다.
  - 투입: `C` 키 또는 **「코인 넣기 (C)」** 버튼 탭
  - 이어하기: `SPACE`, CONTINUE 화면 탭, 또는 **「크레딧으로 계속하기」** 버튼
- 시간 안에 이어하지 않으면(또는 크레딧이 없으면) **타이틀 화면으로 돌아갑니다.**

## 조작법

### 모바일 (터치)

- 플레이 중: 화면 어디든 손가락을 대고 **좌우로 끌어(drag)** 플레이어(용)를 이동시킵니다.
  - 손가락 X 좌표가 용의 목표 위치가 됩니다. 손을 떼면 그 자리에 멈춥니다.
- 타이틀/컨티뉴 화면: 빈 곳 탭 = 코인 투입(타이틀) / 이어하기(컨티뉴), 아래 버튼으로도 조작 가능합니다.
- 발사는 자동이라 별도 발사 버튼이 없습니다.

### PC (키보드·마우스)

| 입력 | 동작 |
|------|------|
| `←` / `→` 키 | 플레이어(용) 좌우 이동 |
| 마우스 이동 (게임 화면 위) | 마우스 위치로 용 이동 (호버 추적) |
| `C` 키 | 크레딧 코인 투입 (타이틀·컨티뉴 화면) |
| `SPACE` | 시작 / 컨티뉴 이어하기 (크레딧 필요) |

공격은 플레이어가 자동으로 계속 발사합니다. 별도 발사 키가 필요 없습니다.

## 게임 규칙

- 플레이어는 화면 아래에서 좌우로만 움직입니다.
- 적은 가로 한 줄(웨이브) 단위로 위에서 내려옵니다. 체력이 있어 총알을 맞으면 줄어들고 0이 되면 쓰러집니다. 적·운석·적 총알에 닿으면 게임 오버입니다.
- 쓰러진 적은 코인을 떨어뜨리고, 확률적으로 아이템을 드롭합니다:
  - **화력 강화(빨간 상자)**: 발사 패턴 강화 (최대 Lv.3)
  - **자석(파란 상자)**: 주변 코인을 끌어당김 (8초)
  - **방어막(초록 상자)**: 잠시 무적 + 적 접촉 시 적 제거 (6초)
- 운석이 떨어지기 전, 해당 줄에 노란 경고 표시(`!`과 가이드 라인)가 먼저 나타납니다.
- 스테이지 종료 직전 거대한 **보스 용**이 등장해 총알을 쏩니다. 처치하면 다음 스테이지로 진행합니다.
- 점수 = 이동 거리 + 처치 수 + 코인 획득 (+ 보스 처치 보너스). 스테이지가 오를수록 난도가 올라갑니다.
- HUD에 스테이지(STAGE)·점수(SCORE)·크레딧(CREDIT)·코인(COIN)·처치(KILL)와 현재 버프 상태를 표시합니다.

## 모바일 표시 최적화

- `viewport` 메타에 `viewport-fit=cover`, 사용자 확대 비활성화를 적용했습니다.
- 캔버스는 화면 비율(480:720)을 유지하면서 세로 긴 휴대폰 화면에 꽉 차도록 `min()/aspect-ratio`로 자동 조정됩니다.
- HUD·오버레이는 `env(safe-area-inset-*)`를 반영해 노치·홈바 영역을 피합니다.
- 작은 화면(≤520px)에서는 폰트·간격이 자동으로 축소됩니다.
- 캔버스에 `touch-action: none`, 버튼에 `touch-action: manipulation`을 설정해 스크롤·더블탭 확대 없이 드래그 조작에만 집중합니다.

## 파일 구성

```
simple_llm_test_ff_dragonflight_v3/
├── index.html   # 진입점: 캔버스 + HUD(STAGE/CREDIT) + 타이틀/게임오버/컨티뉴 화면 + 코인 버튼
├── style.css    # 레이아웃·HUD·스테이지 배너·크레딧/컨티뉴 UI 스타일 (모바일 대응)
├── game.js      # 게임 로직(스테이지 진행, 크레딧/컨티뉴 상태, 플레이어, 적 웨이브, 보스, 운석, 코인/아이템, 충돌, 렌더링, 터치 입력)
└── README.md    # 이 문서
```

## 참고

- 외부 라이브러리·폰트·이미지·오디오 파일 없이 순수 JavaScript로 동작합니다.
- 모든 캐릭터와 효과는 `game.js` 내 Canvas 드로잉 함수(`drawPlayer`, `drawEnemy`, `drawMeteor` 등)로 실시간 생성됩니다.
