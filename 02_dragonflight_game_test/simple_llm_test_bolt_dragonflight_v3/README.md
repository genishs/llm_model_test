# 드래곤플라이트 - 세로 스크롤 슈팅 게임

웹 브라우저에서 바로 실행되는 HTML5 기반 세로 스크롤 슈팅 게임입니다. 모바일 게임 「드래곤플라이트」의 게임성을 참고하여 제작했으며, 모든 그래픽은 코드로 직접 그린 벡터 도형입니다.

## 파일 구성

```
simple_llm_test_bolt_dragonflight_v3/
├── index.html    # 게임 전체 (HTML + CSS + JS 통합)
└── README.md     # 이 파일
```

별도의 설치, 빌드, 서버가 필요 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 실행 방법

1. `index.html` 파일을 더블 클릭하거나
2. 브라우저에서 `index.html`을 열어 주세요.

## 조작법

| 입력 | 동작 |
|------|------|
| ← / → 키보드 | 플레이어(용) 좌우 이동 |
| 마우스 드래그 | 마우스 왼쪽 버튼을 누른 채 드래그하여 이동 |
| 터치 드래그 | 화면을 터치한 채 손가락을 좌우로 드래그하여 이동 (모바일) |
| 공격 | 자동으로 지속 발사 (수동 조작 불필요) |

## 스테이지(레벨) 규칙

- **스테이지**: 화면 왼쪽 상단(또는 스테이지 표시 영역)에 현재 스테이지가 표시됩니다.
- **스테이지 상승**: 일정 거리(기본 약 500m)를 누적할 때마다 스테이지가 1 상승합니다. 스테이지가 오를수록 적의 속도와 체력이 증가하고, 난이도가 높아집니다.
- **보스**: 일정 거리마다 보스가 등장하며, 보스를 처치하면 다음 스테이지로 진행됩니다.
- **크레딧 획득**: 스테이지가 상승할 때마다 크레딧이 1 회복됩니다. 보스를 쓰러뜨릴 때 일정 확률로 「크레딧 코인」이 드롭되며, 이를 줍으면 크레딧이 1 회복됩니다.

## 크레딧(코인) 개념

- **크레딧**: 게임을 시작하거나 이어하기에 소비되는 게임 내 currency입니다. 화면 상단에 크레딧 바와 남은 크레딧 수로 표시됩니다.
- **크레딧 코인**: 게임 플레이 중 아이템으로 드롭되는 전용 코인입니다. 노란색 원형으로, 일반 코인(황색)과 구분됩니다. 키보드나 터치로 플레이어와 닿으면 크레딧이 1 회복됩니다.
- **크레딧 조작**:
  - 게임 시작: 크레딧이 1 이상일 때만 시작 가능하며, 시작 시 크레딧 1을 소비합니다.
  - 이어하기(컨티뉴): 게임 오버 후 크레딧이 있으면 이어서 할 수 있으며, 이어하기 시 크레딧 1을 소비합니다.
  - 크레딧이 0이면 시작/이어하기 버튼이 비활성화(클릭 시 무시)됩니다.
- **저장**: 크레딧과 스테이지는 브라우저 로컬 스토리지에 저장되어, 브라우저를 닫아도 유지됩니다.

## 컨티뉴(이어하기) 규칙

- **게임 오버**: 적·운석과의 충돌 또는 화면 하단으로 적이 내려오면 게임 오버가 됩니다.
- **컨티뉴 화면**: 게임 오버 시 3초 카운트다운과 함께 컨티뉴 화면이 표시됩니다.
- **이어하기**: 화면 내 「이어하기」 버튼을 누르거나 카운트다운 중에 터치/클릭하면 크레딧 1을 소비하고, 현재 점수와 스테이지를 유지한 채 이어서 플레이합니다.
- **시간 초과**: 3초 안에 이어하지 않으면 타이틀 화면으로 돌아갑니다. 타이틀로 돌아가도 점수·스테이지는 유지(로컬 스토리지)되지만, 다음 시작은 새 게임으로 진행됩니다.

## 게임 흐름

타이틀(대기) 화면 → 크레딧 확인 후 시작 → 플레이 → 게임 오버 → 컨티뉴 화면(3초 카운트다운) → 이어하기(크레딧 소비) 또는 타이돌 복귀 → 타이틀

## 아이템

- **코인(황색)**: 일반 아이템으로, 줍면 코인 수 +1입니다.
- **크레딧 코인(노랑)**: 전용 아이템으로, 줍면 크레딧 +1입니다.
- **공격 강화(보라)**: 일시적 시각 효과.
- **방어막(하늘)**: 일시적 시각 효과.

## 저장 사항

최고 점수, 크레딧, 스테이지는 브라우저 로컬 스토리지에 자동으로 저장됩니다. 게임 오버 화면에서 최고 점수를 확인할 수 있으며, 브라우저를 닫아도 크레딧과 스테이지는 유지됩니다.
