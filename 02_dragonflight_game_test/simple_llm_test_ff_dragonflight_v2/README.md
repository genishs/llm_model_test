# Dragonflight (세로 스크롤 슈팅)

웹 브라우저에서 바로 실행되는 HTML5 Canvas 기반 세로 스크롤 슈팅 게임입니다.
모바일 게임 「드래곤플라이트」의 게임성을 참고했으나, 모든 그래픽은 Canvas로 직접 그려
원작의 이미지·소리·이름 에셋은 사용하지 않았습니다.

## 실행 방법

설치·빌드·서버가 필요 없습니다. 아래 두 가지 중 하나로 열면 바로 실행됩니다.

- `index.html` 파일을 브라우저(Chrome, Edge, Firefox 등)로 더블클릭하여 열기
- 또는 이 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속 (선택)

## 조작법

### 모바일 (터치)

- 화면 어디든 손가락을 대고 **좌우로 끌어(drag)** 플레이어(용)를 이동시킵니다. 손가락 X 좌표가 용의 목표 위치가 됩니다.
- 손가락을 떼면 용은 그 자리에 멈춥니다 (마우스 호버 추적과는 다르게 동작).
- 시작 화면·게임오버 화면 어디서나 **탭**하면 게임이 시작/재시작됩니다. 아래 버튼도 그대로 사용 가능합니다.
- 발사는 자동이라 별도 터치 버튼이 필요 없습니다.
- 첫 게임 시작 시 하단에 "화면을 손가락으로 좌우로 끌어 이동" 안내가 잠시 표시됩니다.

### PC (키보드·마우스)

| 입력 | 동작 |
|------|------|
| `←` / `→` 키 | 플레이어(용) 좌우 이동 |
| 마우스 이동 (게임 화면 위) | 마우스 위치로 용 이동 (호버 추적) |
| `SPACE` / 시작 버튼 클릭 | 게임 시작 · 재시작 |

공격은 플레이어가 자동으로 계속 발사합니다. 별도 발사 키가 필요 없습니다.

## 게임 규칙

- 플레이어는 화면 아래에서 좌우로만 움직입니다.
- 적은 가로 한 줄(웨이브) 단위로 위에서 내려옵니다. 체력이 있어 총알을 맞으면 줄어들고 0이 되면 쓰러집니다. 적·운석·적 총알에 닿으면 게임 오버입니다.
- 쓰러진 적은 코인을 떨어뜨리고, 확률적으로 아이템을 드롭합니다:
  - **화력 강화(빨간 상자)**: 발사 패턴 강화 (최대 Lv.3)
  - **자석(파란 상자)**: 주변 코인을 끌어당김 (8초)
  - **방어막(초록 상자)**: 잠시 무적 + 적 접촉 시 적 제거 (6초)
- 운석이 떨어지기 전, 해당 줄에 노란 경고 표시(`!`과 가이드 라인)가 먼저 나타납니다.
- 일정 거리마다 거대한 **보스 용**이 등장해 총알을 쏩니다.
- 점수 = 이동 거리 + 처치 수 + 코인 획득. 진행할수록 스크롤 속도·적 체력·웨이브 밀도가 올라갑니다.
- HUD에 점수(SCORE)·거리(DIST)·코인(COIN)·처치(KILL)와 현재 버프 상태를 표시합니다.

## 모바일 표시 최적화

- `viewport` 메타에 `viewport-fit=cover`, 사용자 확대 비활성화를 적용했습니다.
- 캔버스는 화면 비율(480:720)을 유지하면서 세로 긴 휴대폰 화면에 꽉 차도록 `min()/aspect-ratio`로 자동 조정됩니다.
- HUD·오버레이는 `env(safe-area-inset-*)`를 반영해 노치·홈바 영역을 피합니다.
- 작은 화면(≤520px)에서는 폰트·간격이 자동으로 축소됩니다.
- 캔버스에 `touch-action: none`, 버튼에 `touch-action: manipulation`을 설정해 스크롤·더블탭 확대 없이 드래그 조작에만 집중합니다.

## 파일 구성

```
simple_llm_test_ff_dragonflight_v2/
├── index.html   # 진입점: 캔버스 + HUD + 시작/게임오버 화면 + 터치 힌트
├── style.css    # 레이아웃·HUD·오버레이 스타일 (모바일 대응)
├── game.js      # 게임 로직(플레이어, 적 웨이브, 보스, 운석, 코인/아이템, 충돌, 렌더링, 터치 입력)
└── README.md    # 이 문서
```

## 참고

- 외부 라이브러리·폰트·이미지·오디오 파일 없이 순수 JavaScript로 동작합니다.
- 모든 캐릭터와 효과는 `game.js` 내 Canvas 드로잉 함수(`drawPlayer`, `drawEnemy`, `drawMeteor` 등)로 실시간 생성됩니다.
