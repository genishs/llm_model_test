# Dragonflight - 웹 세로 스크롤 슈팅 게임

## 소개

모바일 게임 「드래곤플라이트」에서 영감을 받은 간단한 HTML5 세로 스크롤 슈팅 게임입니다. 화면 아래에서 좌우로만 움직이는 용(플레이어)이 자동으로 총을 쏘며, 위에서부터 웨이브 형태로 적(용)이 내려옵니다. 적을 맞추면 체력이 감소하고, 0이 되면 쓰러지며 코인을 떨어뜨립니다. 아이템(공격 강화, 자석, 방어막)도 가끔 등장합니다.

이 버전에는 **스테이지(레벨)**, **크레딧**, **컨티뉴** 시스템이 추가되어 아케이드 게임처럼 작동합니다.

## 실행 방법

- **필요한 것**: 웹 브라우저 (Chrome, Firefox, Safari 등)
- **방법**: `index.html` 파일을 브라우저로 바로 열기만 하면 됩니다. 별도의 설치나 서버가 필요하지 않습니다.

## 조작법

- **키보드**: ← / → (또는 A / D) 키로 용을 좌우 이동
- **마우스**: 마우스를 움직여 용을 수평으로 조절
- **터치**: 화면에서 손가락을 드래그하여 좌우로 이동
- **시작/재시작**: 화면을 클릭하거나 시작 화면의 버튼을 누릅니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 게임 본체 (HTML + CSS + JavaScript) - 모든 게임 로직이 포함됨 |
| `README.md` | 이 파일 - 게임 소개, 실행 방법, 조작법, 게임 규칙 요약 |

## 게임 규칙 요약

- 플레이어는 화면 아래에서 좌우로만 이동, 자동 사격
- 적은 가로 웨이브로 하강, 체력 감소 → 쓰러지면 코인 및 아이템 드롭
- 일정 거리마다 보스 등장, 진행 시 속도·적 체력 상승
- 점수 = 거리 × 10 + 코인 × 50, 거리·코인·점수를 화면에 표시
- **스테이지(레벨)**: 보스를 쓰러뜨리면 다음 스테이지로 넘어감. 스테이지는 1부터 시작하며, 보스가 등장할 때마다 난이도가 상승합니다.

## 스테이지 (Stage)

- **정의**: 게임을 진행하는 단계로, 보스를 한 번 쓰러뜨릴 때마다 다음 단계로 넘어갑니다.
- **표시**: 화면 왼쪽 위에 현재 스테이지 번호가 표시됩니다 (`Stage: X`).
- **난이도**: 스테지가 올라갈수록 적의 속도와 체력이 증가하여 더 어려운 게임이 됩니다. 보스는 3번째 웨이브마다 등장하며, 스테이지가 높아질수록 체력과 공격력이 상승합니다.

## 크레딧 (Credits)

- **수집**: 적이나 아이템을 줍는 과정에서 **크레딧 코인**이 드롭됩니다. 크레딧 코인은 일반 코인과 색상이 다르며, 화면 하단에 금색(#ffd700)으로 표시됩니다.
- **표시**: 화면의 크레딧 항목에서 남은 크레딧 수를 확인할 수 있습니다.
- **사용**: 게임 오버 후 **계속** 화면에서 크레딧을 소모하여 게임을 이어갈 수 있습니다. 점수와 스테이지는 유지됩니다.
- **주의**: 크레딧이 없으면 계속할 수 없으며, 계속하지 못하면 타이틀 화면으로 돌아갑니다.

## 컨티뉴 (Continue)

- **게임 오버 시**: 화면에 카운트다운(3초)과 함께 계속 버튼이 표시됩니다.
- **계속 조건**: 크레딧이 1개 이상 있을 경우, 버튼을 누르면 크레딧을 소모하고 점수와 스테이지는 유지한 채 게임을 재개합니다.
- **타이틀으로 복귀**: 카운트다운 기간 내에 계속 버튼을 누르지 않으면 타이틀 화면으로 돌아갑니다.

## 게임 흐름

1. **타이틀(대기) 화면** - 게임 소개와 크레딧 현황 표시
2. **시작** - 클릭 또는 시작 버튼으로 게임 시작 (점수·거리·코인·크레딧 초기화)
3. **플레이** - 적을 피하고 점수를 얻으며 진행
4. **게임 오버** - 적에게 맞거나 거리 제한 초과 시 종료
5. **컨티뉴** - 카운트다운 후 크레딧으로 계속 (점수·스테이지 유지) 또는 타이틀 화면 복귀
6. **타이틀** - 다시 시작 가능

전체 흐름은 끊김 없이 연결되어 있으며, 별도 설치나 서버 없이 `index.html`만 브라우저에서 열면 바로 실행됩니다.
