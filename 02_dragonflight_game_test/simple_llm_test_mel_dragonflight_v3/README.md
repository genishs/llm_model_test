# DragonFlight

HTML 기반의 오프라인 게임으로, 브라우저에서 바로 실행 가능합니다.

## 실행 방법
1. 이 폴더(`simple_llm_test_mel_dragonflight_v1`)에 `index.html`을 엽니다.
2. 브라우저에서 파일을 열거나 주소창에 파일 경로를 입력합니다.

## 조작법
- **← / → 키**: 키보드로 좌우로移动
- **Enter / Space**: 게임 시작
- **터치**: 화면을 손가락으로 가로지르면 좌쪽이나 우측으로 이동
- 마우스: 현재는 사용되지 않지만, 향후 확장을 위해 준비되었습니다.

## 파일 구성
- `index.html`: 게임 실행 파일

## 게임 설명
플레이어(용)가 화면 아래에서 좌우로 움직이며, 적(용)이 위에서 내려오는 웨이브를 피해야 합니다. 적을 맞으면 코인을 떨어뜨리고, 쓰러진 적에게 아이템을 찾을 수 있습니다. 시간이 지날수록 속도가 빨라지고 보스가 나타나며, 총 점수와 코인 수가 표시됩니다.

## 기타
- 별도의 설치 없이 브라우저만으로 실행됩니다.
- 게임 오버 후 다시 시작할 수 있습니다.
- 스테이지는 게임 진행에 따라 증가하며, 적의 속도가 증가합니다.
- 크레딧은 'c' 키 또는 탭으로 삽입 가능하며, 체크포인트에서 크레딧을 사용해 다시 시작할 수 있습니다.
- 체크포인트 화면에서 시간이 초과되면 게임이 제목 화면으로 리셋됩니다.
