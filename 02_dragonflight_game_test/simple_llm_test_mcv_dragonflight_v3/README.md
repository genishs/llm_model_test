# DragonFlight - 세로 스크롤 슈팅 게임

모바일 게임「드래곤플라이트」의 게임성을 참고한 HTML5 기반 세로 스크롤 슈팅 게임입니다. 아케이드 게임처럼 스테이지, 크레딧, 컨티뉴 시스템을 도입했습니다.

## 실행 방법

1. `index.html` 파일을 브라우저(Chrome, Firefox, Edge 등)로 직접 열면 바로 실행됩니다.
2. 별도 설치, 빌드, 서버가 필요 없습니다.

## 조작법

- **키보드**: 
  - ← (왼쪽), → (오른쪽) : 플레이어 이동
  - 1, 2, 5 : 크레딧 코인 입력 (1, 2, 5 크레딧 추가)
  - Enter / Space : 게임 시작 / 컨티뉴
- **마우스**: 커서 이동으로 플레이어 제어
- **터치 (모바일)**: 
  - 화면에 손가락을 대고 좌우로 끌어 플레이어 이동
  - 탭 : 크레딧 코인 입력 (1 크레딧 추가) / 게임 시작
- **클릭**: 게임 시작 / 컨티뉴

## 게임 흐름

**타이틀 → 시작 → 플레이 → 게임 오버 → 컨티뉴 → 타이틀**

1. **타이틀 화면**: 크레딧이 0이면 입력 needed. 크레딧이 있으면 Enter/클릭/탭으로 시작.
2. **플레이**: 스테이지별 적과 보스를 쓰러뜨리며 진행.
3. **게임 오버**: 컨티뉴 화면으로 전환, 카운트다운 시작.
4. **컨티뉴**: 시간 안에 크레딧을 입력하고 Enter/클릭/탭으로 이어서 플레이 (점수·스테이지 유지).
5. **타이틀**: 시간 초과 시 타이틀로 돌아감.

## 스테이지 규칙

- **보스討伐 시 다음 스테이지**: 매 5웨이브마다 보스가 등장하며, 보스를 쓰러뜨리면 스테이지가 오릅니다.
- **난이도 증가**: 스테이지가 오를수록 적의 체력과 속도가 증가합니다.
- **스테이지 표시**: 화면 왼쪽 상단에 현재 스테이지가 표시됩니다.

## 크레딧·컨티뉴 방법

### 크레딧 (Credit)
- **크레딧 코인**은 게임 안에서 줍는 코인($ 코인)과 **다릅니다**.
- **입력 방법**: 
  - 키보드: `1`, `2`, `5` 키를 눌러 크레딧을 추가 (최대 99)
  - 터치: 화면 탭 시 1 크레딧 추가
- **사용 방법**: 게임 시작 시 크레딧 1이 소모됩니다.

### 컨티뉴 (Continue)
- **게임 오버** 시 컨티뉴 화면이 나타나고 **3초 카운트다운**이 시작됩니다.
- **컨티뉴 방법**: 카운트다운 중에 크레딧을 입력(1/2/5 키 또는 탭) 후, `Enter`/클릭/탭으로 컨티뉴.
- **컨티뉴 시**: 현재 점수·스테이지가 유지되며, 크레딧 1이 소모되어 게임이 재개됩니다.
- **시간 초과**: 3초 안에 컨티뉴하지 않으면 타이틀 화면으로 돌아갑니다.

## 게임 규칙

1. **플레이어(용)**: 화면 아래에서 좌우로 움직이며, 공격은 자동으로 계속 발사됩니다.
2. **적(용)**: 가로 한 줄 단위의 웨이브로 위에서 내려옵니다. 적마다 체력이 있어 맞으면 줄어들고 0이 되면 쓰러집니다.
3. **충돌**: 적에 닿으면 게임 오버 (방어막 활성화 시 예외).
4. **코인**: 쓰러진 적이 코인을 떨어뜨립니다 (게임 내 코인, 점수 계산에 사용).
5. **아이템**: 가끔 공격 강화, 자석, 방어막 등의 아이템이 나옵니다.
6. **운석**: 떨어지기 전 경고 표시가 먼저 나옵니다.
7. **보스**: 일정 거리(웨이브 5회)마다 보스가 등장하며, 보스를 쓰러뜨리면 다음 스테이지로 넘어갑니다.
8. **점수**: 날아간 거리 + 처치 수 + 코인으로 점수가 매겨집니다.
9. **난이도**: 스테이지가 오를수록 속도와 적 체력이 증가합니다.

## 파일 구성

- `README.md`: 이 파일 (게임 설명 및 조작법)

- Vanilla JavaScript (框架 없이 순수 JS)
- CSS (기본 스타일링)
