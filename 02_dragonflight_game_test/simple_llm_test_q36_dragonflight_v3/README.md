# 드래곤플레이트 (Dragon Flight)

아케이드 스타일의 세로 스크롤 슈팅 게임. 스테이지, 크레딧, 컨티뉴 시스템을 탑재했습니다.

## 파일 구성

```
simple_llm_test_q36_dragonflight_v3/
└── index.html          # 게임 파일 (단일 HTML, 전체 게임 코드 포함)
```

## 실행 방법

1. 폴더 내 `index.html` 파일을 브라우저(Chrome, Firefox, Edge 등)에서 엽니다.
2. 별도 설치·빌드·서버 설정 없이 바로 게임이 실행됩니다.
3. 모바일 기기에서 열면 화면에 맞게 자동 조정됩니다.

## 조작법

### 이동

| 조작 | 방법 |
|------|------|
| 이동 (터치) | 화면에서 손가락을 왼쪽/오른쪽으로 끌어 이동 (모바일) |
| 이동 (키보드) | `←` `→` 화살표 키 또는 `A` `D` 키 |
| 이동 (마우스) | 마우스 커서 이동 |
| 게임 시작 | 터치 / 클릭 / 엔터 / 스페이스바 |

공격은 자동 발사됩니다.

### 모바일 조작 상세

1. **게임 시작**: 게임 화면을 터치하면 바로 시작됩니다.
2. **이동**: 화면의 아무 곳이나 터치한 후 손가락을 **왼쪽** 또는 **오른쪽**으로 드래그합니다.
   - 드래그 거리만큼 용이 좌우로 움직입니다.
   - 손가락을 떼면 이동이 멈춥니다.
3. **재시작**: 게임 오버 화면에서 터치하면 컨티뉴(크레딧 있으면) 또는 타이틀로 돌아갑니다.

## 아케이드 시스템

### 크레딧 (Credit)

- 게임 시작 시 **크레딧 3개**가 주어집니다.
- 크레딧이 있어야 게임을 시작할 수 있습니다.
- 게임 화면 UI 좌상단에 **크레딧** (분홍색)과 **코인** (노란색)이 separately 표시됩니다.

#### 크레딧 추가 방법 (키보드 & 터치)

| 조작 | 방법 |
|------|------|
| 키보드 | `스페이스바` 또는 `엔터` — 타이틀/크레딧 투입 화면에서 크레딧 +1 |
| 터치/클릭 | 게임 화면 터치/클릭 — 타이틀에서 게임 시작 (크레딧 1개 소모) |

> **타이틀 화면**에서 스페이스바/엔터를 누르면 크레딧이 1개 추가됩니다. 크레딧 투입 화면(Insert Credit)에서도 동일하게 추가 가능합니다.

#### 크레딧 vs 게임 코인

| | 크레딧 (Credit) | 게임 코인 (Coin) |
|--|-----------------|-------------------|
| 색상 | 분홍색 (#ff88ff) | 노란색 (#ffcc00) |
| 획득 방법 | 타이틀에서 스페이스바/엔터 | 적 처치 후 떨어지는 코인 수집 |
| 용도 | 게임 시작/컨티뉴에 소모 | 점수 획득 (1개=5점), 아이템 |
| 위치 | UI 좌상단 | UI 좌상단 (크레딧 아래) |

### 컨티뉴 (Continue)

- 게임 오버 시 **3초 카운트다운** 화면이 표시됩니다.
- 컨티뉴하려면 **크레딧 1개**가 소모됩니다.
- 컨티뉴 조건:
  - **키보드**: `스페이스바` / `엔터` / `ESC`
  - **터치/클릭**: 화면 터치/클릭

#### 컨티뉴 절차

1. 게임 오버 화면에서 크레딧이 1개 이상 있으면 컨티뉴가 가능합니다.
2. 터치/클릭/스페이스바/엔터로 컨티뉴를 선택하면 3초 카운트다운이 시작됩니다.
3. 3초 안에 컨티뉴하면 **점수와 스테이지를 유지**하고 게임을 재개합니다.
4. 3초 안에 컨티뉴하지 않으면 **타이틀 화면**으로 돌아갑니다.
5. 크레딧이 0개이면 컨티뉴할 수 없으며, 자동으로 타이틀 화면으로 돌아갑니다.

> **컨티뉴 시**: 점수, 스테이지 번호는 유지됩니다. 플레이어는 무적 상태로 재출발하며, 적들은 현재 스테이지의 첫 웨이브부터 다시 등장합니다.

## 스테이지 규칙

### 기본 구조

- 스테이지는 **5웨이브**마다 진행됩니다.
- 각 스테이지의 **마지막 웨이브(5, 10, 15, ...)**에는 **보스**가 등장합니다.
- 보스를 쓰러뜨리면 해당 스테이지 클리어이고, 자동으로 다음 스테이지로 진행됩니다.
- 스테이지 클리어 시 약 3초간 "스테이지 N CLEAR!" 메시지가 표시됩니다.

### 스테이지별 난이도 증가

| 스테이지 | 웨이브 범위 | 적 수 증가 | 적 HP 증가 | 적 속도 증가 |
|----------|------------|-----------|-----------|-------------|
| 1 | 1~5 | 기본 | 기본 | 기본 |
| 2 | 6~10 | +2 | +2 | +0.2 |
| 3 | 11~15 | +4 | +4 | +0.4 |
| 4 | 16~20 | +6 | +6 | +0.6 |
| N | (N-1)×5+1 ~ N×5 | +2(N-1) | +2(N-1) | +0.2(N-1) |

- **보스 HP**도 스테이지가 오를수록 증가합니다: `40 + 스테이지×20 + 웨이브×3`
- 3웨이브마다 **운석**이 등장합니다 (운석은 스테이지와 무관하게 등장).

### 스테이지 진행 흐름

```
타이틀 → 크레딧 투입 → 게임 시작 → 웨이브 진행 → 보스 등장 → 보스 처치 → 스테이지 클리어 → 다음 스테이지 → ... → 게임 오버 → 컨티뉴 (또는 타이틀)
```

## 게임 규칙

### 기본玩法
- 플레이어(녹색 용)는 화면 아래에서 좌우로 움직입니다.
- 공격은 자동으로 계속 발사됩니다.
- 적(적색 용)은 웨이브 단위로 위에서 내려옵니다.
- 적에 닿거나 운석에 닿으면 게임 오버입니다 (방어막으로 막을 수 있음).

### 적과 웨이브
- 적은 색상에 따라 4종류 (빨강, 주황, 보라, 파랑)
- 각 적마다 체력이 있고, UI에 HP 바 표시
- 적에 닿으면 게임 오버 (방어막 제외)
- **5웨이브마다 보스**가 등장합니다. 보스는 대량 공격을 사용합니다.

### 운석
- 3웨이브마다 운석이 떨어지기 전 화면에 **경고 표시**가 나옵니다.
- 운석에 닿으면 게임 오버 (방어막으로 막을 수 있음)

### 코인과 아이템
- 적을 처치하면 코인을 떨어뜨립니다.
- 가끔 아래 아이템이 drops됩니다:

| 아이템 | 효과 |
|--------|------|
| ⚡ 공격UP (주황) | 공격 레벨 상승 (최대 Lv.5). 탄수·탄속 증가 |
| 🧲 자석 (보라) | 일정 시간 코인 자동 수집 범위 확대 |
| 🛡 방어막 (파랑) | 일정 시간 한 번의 피해 차단 |

### 점수 시스템
- **거리 점수**: 진행 거리에 비례
- **처치 점수**: 적 처치 수 × 웨이브 보정
- **코인 점수**: 수집한 코인 수 × 5
- **보스 처치 보너스**: +1,000점 + 500점
- 진행할수록 적 속도·체력이 증가합니다.

## 게임 화면

- **좌상단**: 점수, 스테이지, 코인, 크레딧
- **중앙 상단**: 현재 웨이브 번호
- **우상단**: 처치 수, 공격 레벨, 방어막/자석 남은 시간
- **보스 전**: 보스 HP 바 및 이름 표시
