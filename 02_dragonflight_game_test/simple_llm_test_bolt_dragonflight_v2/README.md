# 드래곤플라이트 - 세로 스크롤 슈팅 게임

웹 브라우저에서 바로 실행되는 HTML5 기반 세로 스크롤 슈팅 게임입니다. 모바일 게임 「드래곤플라이트」의 게임성을 참고하여 제작했으며, 모든 그래픽은 코드로 직접 그린 벡터 도형입니다.

## 파일 구성

```
simple_llm_test_bolt_dragonflight_v1/
├── index.html    # 게임 전체 (HTML + CSS + JS 통합)
└── README.md     # 이 파일
```

별도의 설치, 빌드, 서버가 필요 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 실행 방법

1. `index.html` 파일을 더블 클릭하거나
2. 브라우저에서 `index.html`을 열어 주세요.

## 조작법

| 입력 | 동작 |
|------|------|
| ← / → 키보드 | 플레이어(용) 좌우 이동 |
| 마우스 드래그 | 마우스 왼쪽 버튼을 누른 채 드래그하여 이동 |
| 터치 드래그 | 화면을 터치한 채 손가락을 좌우로 드래그하여 이동 (모바일) |
| 공격 | 자동으로 지속 발사 (수동 조작 불필요) |

## 게임 규칙

- **플레이어**: 화면 아래에서 좌우로만 이동합니다. 키보드 ←/→, 마우스 드래그, 또는 화면을 터치한 채 손가락을 좌우로 드래그하면 이동합니다. 공격은 자동으로 계속 발사됩니다.
- **적**: 가로 한 줄 단위의 웨이브로 위에서 내려옵니다. 각 적마다 체력이 있으며, 총알에 맞으면 줄어듭니다. 체력 0이면 쓰러집니다.
- **충돌**: 적과 닿으면 게임 오버입니다.
- **아이템**: 쓰러진 적에서 코인이 drop되며, 가끔 공격 강화·방어막 아이템이 나옵니다.
- **운석**: 일정 시간마다 운석이 떨어지기 전에 "운석 경고!" 표시가 뜨며, 운석에 닿으면 게임 오버입니다.
- **보스**: 일정 거리마다 보스가 등장합니다.
- **점수**: 적 처치 수와 날아간 거리에 따라 점수가 매겨집니다. 진행할수록 속도와 적 체력이 올라갑니다.
- **화면 UI**: 점수, 거리, 코인이 실시간으로 표시됩니다.

## 저장 사항

최고 점수는 브라우저 로컬 스토리지에 자동으로 저장됩니다. 게임 오버 화면에서 최고 점수를 확인할 수 있습니다.
