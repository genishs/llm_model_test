# Dragon Flight

웹 브라우저에서 바로 실행되는 HTML5 캔버스 기반 세로 스크롤 슈팅 게임입니다.
모바일 게임 "드래곤플라이트"의 게임성(자동 공격 · 용 캐릭터 · 코인/아이템 수급 · 보스)을 참고하되, 모든 그래픽은 캔버스 API로 직접 그린 것이며 사운드는 WebAudio로 합성한 것입니다. 원작의 어떤 에셋도 사용하지 않습니다.

## 실행 방법

별도 설치·빌드·서버가 필요 없습니다.

```
index.html 파일을 브라우저로 더블클릭(열기)하면 됩니다.
```

- Chrome / Edge / Firefox / Safari 등 최신 브라우저 권장
- 모바일/태블릿의 브라우저에서도 터치로 플레이 가능
- 인터넷 연결 불필요 (완전 오프라인 동작)

## 조작법

| 입력 | 동작 |
|---|---|
| `←` / `→` 또는 `A` / `D` | 용 좌우 이동 (PC 키보드) |
| 마우스 | 포인터 위치를 따라 이동 (PC) |
| **터치 드래그** | 손가락을 화면 위/아래/옆 어디에서든 **좌우로 끄면** 용이 그 이동량만큼 따라 이동 (모바일) |
| `C` / `1` | **크레딧 코인 1개 삽입** (타이틀 화면, PC) |
| 타이틀 화면에서 탭 / 클릭 | **크레딧 코인 1개 삽입** (모바일·PC) |
| 크레딧 ≥ 1일 타이틀에서 탭 / 클릭 / `Enter` / `Space` | **게임 시작** (크레딧 1 소모) |
| CONTINUE 화면에서 탭 / 클릭 / `Enter` / `Space` | **CONTINUE** (크레딧 1 소모, 점수·스테이지 유지) |

- 공격은 **자동 발사**됩니다. 이동에만 집중하면 됩니다.

> **크레딧 코인 ≠ 게임 내 코인**: 아케이드처럼 코인을 *넣어 쌓는* "크레딧"은 시작·CONTINUE에 쓰이며, 게임 중 적을 처치해 *줍는* 금색 코인(`$`)과 이름·표시·역할이 다릅니다.

### 모바일(터치) 조작 방법

1. **코인 넣기** — 타이틀 화면에서 **한 번 탭**하면 크레딧이 1 쌓입니다. (PC에선 `C` 또는 `1`)
2. **시작** — 크레딧이 1 이상이면 타이틀에서 **탭**하면 게임이 시작되고 크레딧 1이 소모됩니다. (또는 `Enter`/`Space`)
3. **이동** — 게임 진행 중 **화면을 손가락으로 누른 채 좌우로 드래그**하면 용이 손가락의 이동량만큼 1:1로 함께 이동합니다.
   - 용의 위치나 화면 하단에 손가락을 둘 필요 없이, **화면 어디서나** 드래그하면 됩니다.
   - 손가락을 뗄 때까지는 용이 마지막 위치에서 멈춥니다.
4. **CONTINUE** — GAME OVER 후 8초 카운트다운 화면이 뜨면 **탭**하면 크레딧 1을 소모하고 계속합니다.
   - **주의** — 모바일에서는 *탭하는 순간*에 동작이 일어나므로, 시작 후 바로 드래그하려면 살짝 기다렸다가 드래그하는 것이 편합니다.

## 게임 흐름 (아케이드)

```
            ┌──────────── 크레딧 1 소모 후 이어하기(점수·스테이지 유지) ────────────┐
            │                                                                      │
 타이틀(대기) ──코인 투입──▶ 시작(크레딧 1 소모) ─▶ 플레이 ─▶ GAME OVER ─▶ CONTINUE(8초)
      ▲                                                                  │
      └──────────────────── 카운트다운 만료 시 (점수 소멸) ◀──────────────────┘
```

- **타이틀(대기) 화면**: 크레딧을 넣고, 크레딧이 있으면 시작합니다.
- **플레이**: 보스를 쓰러뜨리면 다음 스테이지로 자동 진행됩니다.
- **GAME OVER → CONTINUE**: 체력 소진 시 8초 카운트다운 화면이 뜨고, 그 사이 크레딧 1을 소모해 **점수·스테이지 유지** 상태로 이어합니다.
- **타이틀 복귀**: 카운트다운이 끝나도 이어하지 않으면 타이틀 화면으로 돌아갑니다 (그 게임의 점수는 사라짐).

## 스테이지 규칙

- 화면 상단에 **`STAGE n`** 으로 현재 스테이지가 표시됩니다.
- 일정 거리마다 **보스**가 등장합니다. **보스를 쓰러뜨리면 스테이지가 +1** 되며(배너 `STAGE n` 표시), 다음 스테이지로 넘어갑니다.
- 스테이지가 오를수록:
  - 보스 체력·공격 패턴 강화,
  - 적 체력(`enemyHpMult`)·웨이브 밀도·탄막·운석 빈도 증가,
  - 스크롤 속도가 오름.
- CONTINUE 시에는 **스테이지·점수·거리가 그대로 유지**되고, 체력만 회복하여 다시 플레이합니다.

## 크레딧(코인 삽입)

- 아케이드처럼 **코인을 넣어 크레딧을 쌓습니다**. 크레딧은 게임 시작·CONTINUE에 **1씩 소모**됩니다.
- **크레딧 0이면 시작할 수 없습니다** (타이틀에 "코인을 먼저 넣어주세요" 표시).
- 삽입 방법:
  - **PC 키보드**: `C` 또는 `1`
  - **터치/마우스**: 타이틀 화면을 **탭/클릭**
  - 최대 99까지 쌓을 수 있으며, 남은 크레딧은 타이틀 하단 **CREDIT** 박스와 플레이 중에도 확인 가능합니다.
- 크레딧은 게임 중 적을 처치해 줍는 **게임 내 코인(`$`)과 무관**합니다.

## 게임 규칙

- 플레이어(용)는 화면 아래에서 좌우 이동만 하며 총은 자동으로 쏩니다.
- 적 용은 **가로 한 줄 단위 웨이브**로 위에서 내려옵니다. 적마다 체력이 있어 피격 시 줄고 0이 되면 쓰러집니다.
- **적 몸체에 닿으면 피해를 입습니다** (체력 3, 소진 시 GAME OVER → CONTINUE 화면).
- 쓰러진 적은 **게임 내 코인(`$`)** 을 떨어뜨리고, 확률적으로 **아이템**이 나옵니다:
  - `P` 공격 강화 (파워 1~3단계, 최대 3연사)
  - `M` 자석 (코인 자동 흡입 8초)
  - `S` 방어막 (다음 1회 피격 무효, 6초)
  - `+` 체력 회복
- **운석**은 떨어지기 전 해당 세로 줄에 `!` 경고를 먼저 표시합니다.
- 일정 거리마다 **보스**가 등장하며, 처치 시 **스테이지 업**(속도·적 체력·탄막 상승).
- 점수 = 비행 거리 + 처치 보너스 + 코인 + 보스 처치.
- 진행할수록 스크롤 속도·적 체력·탄막이 어려워집니다.

## 기술 요약

- 순수 vanilla JavaScript (외부 라이브러리 0)
- 로직 해상도 420×740을 CSS/DPR 스케일링으로 어떤 화면에든 맞춰 표시
- 모바일 대응: `pointer events` 기반 **터치 드래그** 입력 (pointerType으로 터치/마우스 구분) + `touch-action: none`, `viewport-fit=cover` 등 모바일 뷰포트 세팅
- `requestAnimationFrame` 고정 스텝 업데이트
- 사운드: WebAudio 오실레이터/노이즈 합성 (파일 없음)
