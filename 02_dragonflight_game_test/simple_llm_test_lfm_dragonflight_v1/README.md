# Dragonflight - 웹 세로 스크롤 슈팅 게임

## 소개

모바일 게임 「드래곤플라이트」에서 영감을 받은 간단한 HTML5 세로 스크롤 슈팅 게임입니다. 화면 아래에서 좌우로만 움직이는 용(플레이어)이 자동으로 총을 쏘며, 위에서부터 웨이브 형태로 적(용)이 내려옵니다. 적을 맞추면 체력이 감소하고, 0이 되면 쓰러지며 코인을 떨어뜨립니다. 아이템(공격 강화, 자석, 방어막)도 가끔 등장합니다.

## 실행 방법

- **필요한 것**: 웹 브라우저(Chrome, Firefox, Safari 등)
- **방법**: `index.html` 파일을 브라우저로 바로 열기만 하면 됩니다. 별도의 설치나 서버가 필요하지 않습니다.

## 조작법

- **키보드**: ← / → (또는 A / D) 키로 용을 좌우 이동
- **마우스**: 마우스를 움직여 용을 수평으로 조절
- **시작/재시작**: 화면을 클릭하거나 시작 화면의 버튼을 누릅니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 게임 본체 (HTML + CSS + JavaScript) - 모든 게임 로직이 포함됨 |
| `README.md` | 이 파일 - 게임 소개, 실행 방법, 조작법, 파일 구성 설명 |

## 게임 규칙 요약

- 플레이어는 화면 아래에서 좌우로만 이동, 자동 사격
- 적은 가로 웨이브로 하강, 체력 감소 → 쓰러지면 코인 및 아이템 드롭
- 적 맞닿으면 게임 오버
- 운석 떨어지기 전 경고 표시 표시
- 일정 거리마다 보스 등장, 진행 시 속도·적 체력 상승
- 점수 = 거리 × 10 + 코인 × 50, 거리·코인·점수를 화면에 표시
- 시작 화면, 게임 오버, 다시 시작 기능 제공
