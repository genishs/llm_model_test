# DragonFlight - 세로 스크롤 슈팅 게임

모바일 게임「드래곤플라이트」의 게임성을 참고한 HTML5 기반 세로 스크롤 슈팅 게임입니다.

## 게임 소개

플레이어는 용(dragon)을 조종하여 위에서 내려오는 적 용들로부터 survival합니다. 공격은 자동으로 발생하며, 좌우로 움직여 적과 운석을 피하고 코인 및 아이템을 수집합니다.

## 실행 방법

1. `index.html` 파일을 브라우저(Chrome, Firefox, Edge 등)로 직접 열면 바로 실행됩니다.
2. 별도 설치, 빌드, 서버가 필요 없습니다.

## 조작법

- **키보드**: ← (왼쪽), → (오른쪽) 이동
- **마우스**: 커서 이동으로 플레이어 제어
- **클릭**: 시작 화면/게임오버 화면에서 게임 시작

## 게임 규칙

1. **플레이어(용)**: 화면 아래에서 좌우로 움직이며, 공격은 자동으로 계속 발사됩니다.
2. **적(용)**: 가로 한 줄 단위의 웨이브로 위에서 내려옵니다. 적마다 체력이 있어 맞으면 줄어들고 0이 되면 쓰러집니다.
3. **충돌**: 적에 닿으면 게임 오버 (방어막 활성화 시 예외).
4. **코인**: 쓰러진 적이 코인을 떨어뜨립니다.
5. **아이템**: 가끔 공격 강화, 자석, 방어막 등의 아이템이 나옵니다.
6. **운석**: 떨어지기 전 경고 표시가 먼저 나옵니다.
7. **보스**: 일정 거리(웨이브 5회)마다 보스가 등장합니다.
8. **점수**: 날아간 거리 + 처치 수 + 코인으로 점수가 매겨집니다.
9. **난이도**: 진행할수록 속도와 적 체력이 증가합니다.

## 파일 구성

- `index.html`: 메인 HTML 파일
- `game.js`: 게임 로직 및 렌더링 코드
