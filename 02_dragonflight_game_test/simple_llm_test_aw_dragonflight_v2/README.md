# Dragon Flight Game

HTML5 canvas 기반의 드래곤 비행 게임입니다. 브라우저에서 바로 실행할 수 있으며, 데스크톱과 모바일 기기 모두에서 플레이할 수 있습니다.

## 게임 방법

### 데스크톱 조작
- **좌우 이동**: 방향키 (← →) 또는 A / D 키

### 모바일 조작 (터치)
- **좌우 이동**: 화면을 터치한 후 손가락을 왼쪽 또는 오른쪽으로 끌어당기며 이동 (Touch & Drag)

## 게임 목표

- 떨어지는 장애물을 피하세요.
- 장애물을 피할 때마다 점수가 증가합니다.
- 가능한 오래 생존하여 높은 점수를 기록하세요.

## 실행 방법

1. `index.html` 파일을 파일 탐색기에서 더블 클릭하거나, 브라우저에 드래그 앤 드롭하여 엽니다.
2. 별도의 설치, 빌드, 또는 서버 구성이 필요 없습니다.
3. 브라우저에서 즉시 게임이 시작됩니다.

## 기술 스택

- HTML5 Canvas
- Vanilla JavaScript
- CSS3 (Responsive Design)
