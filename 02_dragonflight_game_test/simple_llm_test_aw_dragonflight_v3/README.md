# Dragon Flight Game - Arcade Edition

HTML5 canvas 기반의 아케이드 스타일 드래곤 비행 게임입니다. 브라우저에서 바로 실행할 수 있으며, 데스크톱과 모바일 기기 모두에서 플레이할 수 있습니다.

## 게임 방법

### 데스크톱 조작
- **좌우 이동**: 방향키 (← →) 또는 A / D 키
- **크레딧 삽입**: 'I' 키
- **게임 시작**: 'S' 키
- **컨티뉴**: 'C' 키
- **컨티뉴 거부**: 'N' 키

### 모바일 조작 (터치)
- **좌우 이동**: 화면을 터치한 후 손가락을 왼쪽 또는 오른쪽으로 끌어당기며 이동 (Touch & Drag)
- **버튼 조작**: 타이틀, 게임 오버, 컨티뉴 화면의 버튼 터치

## 크레딧 시스템

- **크레딧 코인**: 게임 내에서 점수를 얻는 '코인'과 별도로, 게임을 시작하기 위해 필요한 '크레딧'이 있습니다.
- **크레딧 삽입**: 타이틀 화면에서 'INSERT CREDIT' 버튼을 누르거나 키보드 'I' 키를 눌러 크레딧을 추가합니다.
- **게임 시작**: 크레딧이 1 이상 있어야 'START GAME' 버튼이 활성화되며, 게임 시작 시 크레딧 1이 소모됩니다.
- **크레딧 표시**: 화면 왼쪽 상단에 'CREDITS: X'로 현재 남은 크레딧 수가 표시됩니다.

## 스테이지 규칙

- **스테이지 진행**: 점수가 500점, 1000점, 1500점... 도달 시 보스 전투가 시작됩니다.
- **보스 전투**: 보스를 10초간 피하며 생존하면 보스가 쓰러지고 다음 스테이지로 진행됩니다.
- **난이도 증가**: 스테이지가 오를수록 게임 속도가 빨라지고 장애물 발생 간격이 짧아집니다.
- **스테이지 표시**: 화면 중앙에 'STAGE X' 메시지가 표시됩니다.

## 컨티뉴 시스템

- **게임 오버**: 장애물과 충돌 시 게임 오버 화면이 표시됩니다.
- **컨티뉴 화면**: 게임 오버 후 'CONTINUE' 버튼을 누르거나 'C' 키를 입력하면 컨티뉴 화면이 표시되며 10초 카운트다운이 시작됩니다.
- **컨티뉴 비용**: 컨티뉴 시 크레딧 1이 소모되며, 점수와 스테이지는 유지됩니다.
- **시간 제한**: 10초 안에 컨티뉴하지 않거나 'DECLINE'을 선택하면 타이틀 화면으로 돌아갑니다.

## 게임 목표

- 떨어지는 장애물을 피하세요.
- 장애물을 피할 때마다 점수가 10점 증가합니다.
- 점수가 500점 도달 시 보스가 나타납니다. 보스를 10초간 피하여 생존하면 다음 스테이지로 진행됩니다.
- 가능한 오래 생존하여 높은 점수를 기록하세요.

## 실행 방법

1. `index.html` 파일을 파일 탐색기에서 더블 클릭하거나, 브라우저에 드래그 앤 드롭하여 엽니다.
2. 별도의 설치, 빌드, 또는 서버 구성이 필요 없습니다.
3. 브라우저에서 즉시 게임이 시작됩니다.
