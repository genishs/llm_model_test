# DragonFlight - 세로 스크롤 슈팅 게임

## 🐉 게임 소개

**DragonFlight**는 모바일 게임「드래곤플라이트」의 게임성을 참고하여 직접 제작한 웹 기반 세로 스크롤 슈팅 게임입니다.

- **플레이어(용)**: 자동 발사와 함께 좌우 이동으로 적을 물리칩니다
- **적(용)**: 웨이브 단위로 내려오며 체력이 있습니다
- **운석**: 경고 후 떨어지는 위협적인 장애물
- **보스**: 5단계마다 등장하는 강력한 적
- **코인 & 아이템**: 처치 보상으로 획득 가능

## 🚀 실행 방법

### 브라우저로 바로 실행

1. `index.html` 파일을 브라우저(Chrome, Edge, Safari 등)로 열기
2. 게임 시작 버튼 클릭
3. 조작하여 게임 진행

### 요구 사항

- 최신 웹 브라우저
- 인터넷 연결 불필요 (로컬 파일로 실행 가능)

## 🎮 조작법

### 키보드
- **← / → 화살표**: 좌우 이동
- **자동 발사**: 지속적으로 적 향해 포탄 발사

### 마우스/터치
- **마우스 드래그**: 용을 따라가며 이동
- **모바일 터치**: 터치 지점으로 용 이동

## 🎯 게임 규칙

### 기본 메커니즘
- **점수**: 날아간 거리 + 적 처치 보상
- **거리**: 게임 진행 시 자동 증가 (최대 5000m)
- **코인**: 적 처치 시 획득 (10코인/적)

### 아이템
| 아이템 | 효과 | 표시 |
|--------|------|------|
| **W (Weapon)** | 무기 레벨 업 (1~3단계) | 빨간색 |
| **S (Shield)** | 10초간 무적 방어막 | 파란색 |
| **M (Magnet)** | 10초간 아이템/코인 자동 흡수 | 노란색 |

### 적의 종류
1. **일반 적**: 체력 2~3, 하단에서 내려옴
2. **운석**: 경고 후 떨어짐, 닿으면 게임 오버
3. **보스**: 5단계마다 등장, 강력한 공격

### 난이도 조절
- **wave 수 증가**: 적 속도와 체력 증가
- **웨이브 수**: wave/5 단위로 적 수 증가

## 🎨 그래픽

- **플레이어(용)**: 오렌지색 몸통, 날개, 불꽃 효과
- **적(용)**: 보라색 몸통, 빨간 눈
- **보스**: 빨간색 대형 용
- **운석**: 회색 암석
- **배경**: 별이 깜빡이는 우주 배경
