# Atari 스타일 테트리스

아타리(Atari) 아케이드 버전의 테트리스를 HTML만으로 구현한 웹 기반 게임입니다. 별도 설치나 빌드 없이 `index.html` 파일을 브라우저에서 바로 실행할 수 있습니다.

## 게임 흐름

1. **타이틀 화면** - 게임 시작 버튼 클릭
2. **플레이** - 테트리스 조작 (키보드 또는 터치)
3. **게임 오버** - 카운트다운 후 컨티뉴 또는 타이틀 화면으로 복귀
4. **컨티뉴** - 남은 크레딧으로 계속 (점수·레벨 유지)
5. **타이틀 화면** - 다시 시작 가능

## 레벨 규칙

- **레벨 상승**: 클리어한 줄 수에 따라 레벨이 올라갑니다.
- **점수**: 줄이 클리어될 때마다 점수가 주어지며, 레벨이 올라갈수록 속도가 빨라집니다.
- **낙하 속도**: 레벨 1에서 1000ms, 레벨이 올라갈 때마다 80ms씩 감소 (최소 100ms).
- **화면 표시**: 현재 레벨이 화면에 표시됩니다.

## 크레딧 시스템

- **코인 수집**: 게임 중 코인이 나타나며, 피스가 코인을 덮으면 코인을 획득합니다.
- **크레딧 표시**: 화면 오른쪽에 남은 크레딧이 표시됩니다.
- **컨티뉴 비용**: 게임 오버 후 컨티뉴를 하려면 남은 크레딧 1개를 사용해야 합니다.
- **게임 흐름**: 코인이 없으면 컨티뉴 불가, 시간 내에 계속하지 않으면 타이틀 화면으로 복귀합니다.

## 조작법

### 키보드 (PC)

| 키 | 기능 |
|----|------|
| ← (왼쪽 화살표) | 피스 이동 |
| → (오른쪽 화살표) | 피스 이동 |
| ↓ (아래 화살표) | 피스 하강 |
| ↑ (위 화살표) | 피스 회전 |
| Space | 하드 드롭 (즉시 하강) |
| P | 일시정지 / 재개 |

### 터치 (모바일)

- **왼쪽/오른쪽 스와이프**: 피스 이동 (← / →)
- **아래로 스와이프**: 피스 하강 (↓)
- **탭**: 피스 회전 (↑)
- **P 키**: 일시정지 / 재개 (화면 상단 버튼으로 대체 가능)
