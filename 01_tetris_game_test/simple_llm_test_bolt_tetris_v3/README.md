# Tetris (Atari 1988 Style)

HTML5 Canvas 기반 테트리스 게임입니다. 별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 바로 실행됩니다.

## 실행 방법

1. 폴더 내 `index.html`을 웹 브라우저(Chrome, Edge, Firefox, Safari 등)로 엽니다.
2. 게임이 자동으로 시작됩니다.

## 조작법

### 키보드 (PC)

| 키 | 동작 |
|---|---|
| ← → | 블록 이동 |
| ↑ | 블록 회전 |
| ↓ | 소프트 드롭 (가속 낙하) |
| Space | 하드 드롭 (즉시 낙하 및 고정) |
| P | 일시정지 / 재개 |
| R | 게임 재시작 |

### 터치 (모바일)

화면 하단의 터치 버튼을 사용합니다.

| 버튼 | 동작 |
|---|---|
| ← | 블록 왼쪽 이동 |
| ↑ | 블록 회전 |
| → | 블록 오른쪽 이동 |
| ↓ | 소프트 드롭 (가속 낙하) |
| 드롭 | 하드 드롭 (즉시 낙하 및 고정) |
| 회전 | 블록 회전 |
| 리셋 | 게임 재시작 |

터치 버튼은 모바일 화면(≤600px)에서만 표시됩니다.

## 게임 특징

- Atari Games 1988년 아케이드판 테트리스의 게임성 및 그래픽을 재현
- 7종 테트로미노 (I, O, S, Z, J, L, T) 지원
- 라인 클리어, 레벨 상승, 난이도 가속
- NEXT 미리보기, SCORE / LINES / LEVEL / CREDIT / COIN 표시
- 반응형 레이아웃 (모바일에서도 조작 가능)

## 레벨 규칙

- 지운 줄 수(LINES)가 10줄마다 레벨이 1 상승합니다.
- 레벨이 오를수록 낙하 속도가 빨라집니다(dropInterval: 1000ms → 100ms).
- 현재 레벨은 화면의 LEVEL에서 확인할 수 있습니다.

## 크레딧·컨티뉴 방법

- 코인 삽입: 키보드 1~4 키 또는 모바일 터치 버튼「코인」을 눌러 코인을 넣습니다. 코인 1개당 크레딧 1이 쌓입니다.
- 게임 시작 조건: 크레딧 1 이상이 있어야 게임을 시작할 수 있습니다.
- 게임 오버 후 컨티뉴: 게임 오버 시 크레딧이 남아 있으면 5초 카운트다운과 함께 컨티뉴 화면이 표시됩니다. 키보드 C 키 또는 터치 화면에서 이어하기 버튼을 누르면 점수·레벨을 유지하고 이어서 할 수 있습니다. 시간 안에 이어하지 않으면 타이틀 화면으로 돌아갑니다.
- 남은 크레딧은 화면의 CREDIT, 코인 수는 COIN에서 확인할 수 있습니다.
