# Atari Tetris 1988 - HTML

아타리 게임즈 1988년 아케이드판 테트리스를 웹 브라우저에서 바로 실행되는 단일 HTML 파일로 재현한 버전입니다.

## 게임 소개
- 10×20 보드, 7종 미노
- Atari 1988 아케이드 색감과 픽셀 그래픽
- 레벨 상승 시 드롭 속도 증가, 점수/라인/레벨 표시

## 실행 방법
1. 이 폴더의 `index.html` 파일을 더블 클릭
2. 브라우저에서 바로 실행됩니다. 설치·서버 불필요

## 조작법
- ← → : 좌우 이동
- ↓ : 소프트 드롭
- ↑ / X : 회전
- Space : 하드 드롭
- START / PAUSE 버튼 : 시작/일시정지

### 모바일 터치 조작
- 화면 하단 온스크린 버튼:
  - ◀ : 왼쪽 이동
  - ▶ : 오른쪽 이동
  - ⟳ : 회전
  - ▼ : 소프트 드롭
  - ■ : 하드 드롭
- 보드 영역 스와이프:
  - 좌우 스와이프 : 좌우 이동
  - 아래로 스와이프 : 소프트 드롭
  - 위로 스와이프 : 회전

## 파일 구성
- `index.html` : 게임 전체 코드 포함
- `README.md` : 본 문서

점수: 1줄 40, 2줄 100, 3줄 300, 4줄 1200 × (레벨+1)
