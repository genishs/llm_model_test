# TETRIS — Atari (1988) 재현

웹 브라우저에서 바로 실행되는 **단일 HTML** 테트리스 게임입니다.
아타리(Atari Games)가 1988년에 만든 아케이드판 테트리스의 게임성과 그래픽을 최대한 가깝게 재현했습니다.

설치·빌드·서버가 전혀 필요 없습니다. `index.html`을 더블클릭(또는 브라우저로 열기)하면 바로 실행됩니다.

---

## 실행 방법

1. `index.html` 파일을 브라우저(Chrome / Edge / Firefox / Safari 등)로 엽니다.
   - 파일 탐색기에서 더블클릭, 또는 브라우저 주소창에 파일 경로를 넣는 방식 모두 됩니다.
2. 타이틀 화면에서 **Enter** 키를 누르면 게임이 시작됩니다.

> 인터넷 연결이 필요 없습니다. 모든 코드(CSS/JS)가 하나의 파일에 포함되어 있습니다.

---

## 조작법

| 키 | 동작 |
|------|------|
| `←` / `→` | 피스를 왼쪽/오른쪽으로 이동 |
| `↑` | 피스 회전 (시계방향) |
| `↓` | 소프트 드롭 (가속 하강, 1칸마다 1점) |
| `Enter` | 게임 시작 / 게임 오버 후 다시 시작 |

- **하드 드롭(즉시 낙하)은 없습니다.** 1988년 아타리 원본과 동일하게 `↓` 소프트 드롭만 사용할 수 있습니다.
- 좌우/상단 방향키로 이동·회전, 하단 방향키로 낙하를 가속하는 원본 조작 체계를 따릅니다.
- 화면 하단에 **고스트(반투명 미리보기)**가 표시되어 피스가 어디에 정착하는지 알 수 있습니다.

---

## 게임 규칙 (Atari 1988 방식)

- **보드**: 10열 × 20행.
- **7가지 테트로미노**: I, J, L, O, S, T, Z.
- **하트(생존) 3개**: 쌓인 블록이 상단(상단 4행 안)에 도달하면 하트 1개가 줄어듭니다. 0개가 되면 게임 오버.
- **다음 피스 미리보기**: 우측 패널에 다음 블록을 보여줍니다.
- **레벨**: 10줄을 지울 때마다 레벨이 1씩 올라가고(최대 10), 속도가 빨라집니다.
- **색상**: 레벨 1~9는 아타리 20색 팔레트를, 레벨 10부터는 확장(256색) 팔레트를 사용해 블록 색상이 점점 더 다채로워집니다. 원본과 동일한 방식입니다.

### 점수표 (Atari 1988 공식)

한 번에 지우는 줄 수에 따른 기본점에 `(레벨 + 1)`을 곱합니다. 레벨 10부터는 배율이 `10`이 됩니다.

| 지운 줄 수 | 기본점 |
|:--------:|:------:|
| 1 | 40 |
| 2 | 100 |
| 3 | 300 |
| 4 (테트리스) | 1200 |

- 소프트 드롭: 셀 1칸당 1점.

## 기술 구성

- **HTML5 `<canvas>`**로 렌더링 (픽셀 아트 스타일, 이젤/테두리 효과).
- 순수 **JavaScript (ES5 호환)** 로직 — 외부 라이브러리·프레임워크 없음.
- `requestAnimationFrame` 기반 게임 루프.
- 브라우저 창 크기에 맞춰 캔버스가 자동으로 스케일됩니다.

### 구현된 원본 재현 포인트

- 10×20 보드, 하트 3개, 레벨/스코어/라인 HUD 레이아웃
- 레벨별 색 팔레트 전환 (20색 → 256색)
- Atari 공식 점수표 및 `(레벨+1)` 배율
- 소프트 드롭 점수, 하드 드롭 없음
- 다음 피스 미리보기
- 벽 킥(벽에 붙은 상태에서도 회전 가능)
- 게임 오버 화면 및 재시작

## 주의

- 일부 브라우저에서 `file://` 로 열었을 때 캔버스 읽기 관련 경고가 콘솔에 보일 수 있으나, 게임 실행에는 영향을 주지 않습니다.
- 최상의 경험을 위해 최신 버전의 Chrome / Edge / Firefox / Safari를 권장합니다.
