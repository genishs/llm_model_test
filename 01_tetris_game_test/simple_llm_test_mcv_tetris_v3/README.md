# Tetris - 아케이드 스타일 게임

Atari 1988 스타일의 테트리스 게임입니다. 레벨, 크레딧, 컨티뉴 시스템을 추가했습니다.

## 게임 흐름

1. **타이틀 화면** → 크레딧을 넣고 START
2. **플레이** → 블록을 쌓아 줄을 지움
3. **게임 오버** → 컨티뉴有机会 또는 타이틀로 복귀

## 레벨 규칙

- **10줄을 지울 때마다 레벨이 1 상승**
- 레벨이 오를수록 **낙하 속도가 빨라짐** (level 1: 1000ms, level 10: 100ms)
- 화면 상단에 현재 **LEVEL**이 표시됨
- 점수는 `점수표 * 레벨` 공식으로 계산됨 (1줄: 40, 2줄: 100, 3줄: 300, 4줄: 1200)

## 크레딧·컨티뉴 조작 방법

### 크레딧 (Coin) 추가
- **키보드**: `C` 키 또는 `SPACE` 키 (타이틀/게임오버 화면에서)
- **터치**: `COIN` 버튼 (모바일에서)
- 크레딧이 0이면 게임을 시작할 수 없음

### 게임 시작
- **키보드**: `ENTER` 키 (크레딧 1개 소모)
- **터치**: 타이틀 화면에서 ENTER 대신 크레딧이 있으면 자동 시작 (버튼 없음, ENTER 키만)

### 컨티뉴 (Continue)
- **게임 오버 시** 10초 카운트다운이 시작됨
- **키보드**: `C` 키 또는 `SPACE` 키 (1 크레딧 소모, 점수·레벨 유지)
- **터치**: `COIN` 버튼 (1 크레딧 소모)
- **10초 안에 이어하지 않으면** 타이틀 화면으로 돌아감

## 조작법

### 키보드
- `←` `→` : 블록 이동
- `↑` : 블록 회전
- `↓` : 소프트 드롭 (점점 빠르게 내리기)
- `SPACE` : 하드 드롭 (즉시 낙하)
- `P` : 일시정지/재개
- `ENTER` : 게임 시작
- `C` : 크레딧 추가 (타이틀/게임오버 화면)

### 터치 (모바일)
- `←` `→` `↓` : 블록 이동
- `↻` : 블록 회전
- `DROP` : 하드 드롭
- `COIN` : 크레딧 추가
