# Atari Tetris 1988 - HTML

아타리 게임즈 1988년 아케이드판 테트리스를 웹 브라우저에서 바로 실행되는 단일 HTML 파일로 재현한 버전입니다.

## 게임 소개
- 10×20 보드, 7종 미노
- Atari 1988 아케이드 색감과 픽셀 그래픽
- 레벨 상승 시 드롭 속도 증가, 점수/라인/레벨/크레딧 표시
- 아케이드식 크레딧·컨티뉴 시스템 적용

## 실행 방법
1. 이 폴더의 `index.html` 파일을 더블 클릭
2. 브라우저에서 바로 실행됩니다. 설치·서버 불필요

## 조작법
- ← → : 좌우 이동
- ↓ : 소프트 드롭
- ↑ / X : 회전
- Space : 하드 드롭
- START 버튼 : 게임 시작 (크레딧 필요)
- C 또는 1 : 코인 투입
- Enter : 컨티뉴 선택
- COIN 버튼 : 터치로 코인 투입

### 모바일 터치 조작
- 화면 하단 온스크린 버튼:
  - ◀ : 왼쪽 이동
  - ▶ : 오른쪽 이동
  - ⟳ : 회전
  - ▼ : 소프트 드롭
  - ■ : 하드 드롭
  - COIN : 코인 투입
- 보드 영역 스와이프:
  - 좌우 스와이프 : 좌우 이동
  - 아래로 스와이프 : 소프트 드롭
  - 위로 스와이프 : 회전

## 레벨 규칙
- 지운 줄 수 10줄마다 레벨 상승: `레벨 = floor(라인 / 10) + 1`
- 레벨 상승 시 낙하 속도 증가: `speed = max(20, 1000/(레벨+1))`
- 현재 레벨은 화면 우측에 실시간 표시

## 크레딧·컨티뉴
- 코인 투입: 키보드 C / 1, 또는 COIN 버튼 터치
- 크레딧이 1 이상 있어야 START로 게임 시작 가능. 시작 시 크레딧 1 차감
- 게임 오버 시 10초 카운트다운과 함께 컨티뉴 화면 표시
- 카운트다운 중 Enter 또는 CONTINUE 버튼으로 크레딧 1을 써서 점수·레벨 유지하며 이어서 플레이
- 시간 초과 또는 크레딧 부족 시 타이틀 화면으로 복귀
- 게임 흐름: 타이틀 → 시작 → 플레이 → 게임 오버 → 컨티뉴 → 타이틀

## 파일 구성
- `index.html` : 게임 전체 코드 포함
- `README.md` : 본 문서
