# Arcade Tetris 1988

아타리(Atari) 및 클래식 테트리스의 게임성과 그래픽을 최대한 재현한 웹 기반 테트리스 게임입니다. 크레딧(코인), 레벨, 컨티뉴 개념을 도입한 아케이드 스타일 게임입니다. 별도 설치나 서버 없이 브라우저에서 바로 실행할 수 있습니다.

## 게임 소개

이 게임은 1988년 아케이드에서 인기 있었던 클래식 테트리스의 룰과 그래픽을 기반으로 제작되었습니다. 7가지 테트로미노(I, O, T, S, Z, J, L)를 활용하여 줄을 완성하고 점수를 얻는 전통적인 테트리스 게임입니다. 아케이드 게임처럼 크레딧(코인)을 넣어 게임을 시작하고, 게임 오버 시 크레딧을 사용하여 컨티뉴(계속하기)할 수 있습니다.

## 게임 흐름

1. **타이틀 화면**: "INSERT COIN TO START" 메시지가 표시됩니다.
2. **크레딧 입력**: 'C' 키를 누르거나 COIN 버튼을 탭하여 크레딧을 추가하고 게임을 시작합니다.
3. **플레이**: 테트리스를 진행합니다.
4. **게임 오버**: 모든 줄이 채워져 게임이 끝납니다.
5. **컨티뉴**: 게임 오버 시 크레딧 1개를 사용하여 컨티뉴할 수 있습니다(점수·레벨 유지). 5초 이내에 컨티뉴하지 않으면 타이틀 화면으로 돌아갑니다.
6. **타이틀 화면**: 컨티뉴 시간 초과 또는 타이틀 선택 시 타이틀 화면으로 돌아갑니다.

## 레벨 규칙

- **레벨 상승**: 10줄을 지울 때마다 레벨이 1 상승합니다.
- **낙하 속도**: 레벨이 오를수록 테트리스 블록의 낙하 속도가 빨라집니다.
  - 레벨 1: 1000ms 간격
  - 레벨 2: 900ms 간격
  - 레벨 3: 800ms 간격
  - ... (레벨이 오를 때마다 100ms씩 단축, 최소 50ms)
- 화면 우측 상단에 현재 레벨이 표시됩니다.

## 크레딧·컨티뉴 방법

### 크레딧 추가 (코인 투입)
- **키보드**: 타이틀 화면에서 'C' 키 또는 'Enter' 키를 누릅니다.
- **터치**: 모바일 화면 하단의 "COIN" 버튼을 탭합니다.
- 크레딧 1개로 게임 1회를 시작할 수 있습니다.

### 컨티뉴 (계속하기)
- 게임 오버 시 "CONTINUE (1 CREDIT)" 버튼을 클릭하거나 'C' 키를 누릅니다.
- 컨티뉴 화면에서 5초 카운트다운이 시작됩니다.
- 5초 이내에 'C' 키를 누르거나 컨티뉴 화면을 탭하면 크레딧 1개를 소모하여 게임이 계속됩니다(점수·레벨 유지).
- 5초 이내에 컨티뉴하지 않으면 타이틀 화면으로 돌아갑니다.
- 크레딧이 없으면 컨티뉴가 불가능하고 타이틀 화면으로 돌아갑니다.

## 조작 방법

### 키보드 조작 (PC)
- **이동**: `왼쪽 화살표` ←, `오른쪽 화살표` →
- **소프트 드롭 (빠르게 내리기)**: `아래쪽 화살표` ↓
- **회전**: `위쪽 화살표` ↑
- **하드 드롭 (즉시 낙하)**: `Space` 공간키
- **일시정지/재개**: `P` 또는 `p`
- **크레딧 투입/컨티뉴**: `C` 키 또는 `Enter` 키 (타이틀/컨티뉴 화면에서)

### 터치 조작 (모바일)
- **코인 투입**: "COIN" 버튼 탭
- **이동**: 왼쪽(←) / 오른쪽(→) 버튼 탭 또는 길게 누르기
- **소프트 드롭**: 아래쪽(↓) 버튼 길게 누르기
- **회전**: 회전(↻) 버튼 탭
- **하드 드롭**: DROP 버튼 탭
- **컨티뉴**: 컨티뉴 화면에서 'C' 키 대신 화면 탭 또는 5초 내 대기
