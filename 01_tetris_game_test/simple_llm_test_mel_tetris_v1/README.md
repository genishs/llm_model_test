# Tetris Game (Atari Style)

This is a simple Tetris game that runs directly in the browser without any build step or server.

## Execution
Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).

## Controls
- Arrow keys: Move tetromino left, right, and rotate
- Down arrow: Soft drop (increase speed)
- Space: Hard drop (instantly drop)
- Up arrow: Rotate
- P key: Pause/Resume

## File Structure
- `index.html`: Main HTML file
- `style.css`: Styles for the game UI
- `script.js`: Game logic and rendering

## Game Features
- Classic Tetris gameplay with 7 tetromino shapes
- Score tracking and level progression
- Game over detection
- Simple Atari-style graphics
