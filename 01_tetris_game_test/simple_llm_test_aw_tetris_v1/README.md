# Arcade Tetris 1988

아타리(Atari) 및 클래식 테트리스의 게임성과 그래픽을 최대한 재현한 웹 기반 테트리스 게임입니다. 별도 설치나 서버 없이 브라우저에서 바로 실행할 수 있습니다.

## 게임 소개

이 게임은 1988년 아케이드에서 인기 있었던 클래식 테트리스의 룰과 그래픽을 기반으로 제작되었습니다. 7가지 테트로미노(I, O, T, S, Z, J, L)를 활용하여 줄을 완성하고 점수를 얻는 전통적인 테트리스 게임입니다.

## 실행 방법

1. 이 폴더의 `index.html` 파일을 더블 클릭하거나, 브라우저(Chrome, Firefox, Edge, Safari 등)에 파일을 드래그 앤 드롭합니다.
2. 즉시 게임이 시작됩니다. 별도의 서버 설치나 빌드 과정이 필요하지 않습니다.

## 조작 방법

- **이동**: `왼쪽 화살표` ←, `오른쪽 화살표` →
- **소프트 드롭 (빠르게 내리기)**: `아래쪽 화살표` ↓
- **회전**: `위쪽 화살표` ↑
- **하드 드롭 (즉시 낙하)**: `Space` 공간키
- **일시정지/재개**: `P` 또는 `p`

## 파일 구성

- `index.html`: 게임의 모든 코드(HTML, CSS, JavaScript)가 포함된 단일 파일입니다.
- `README.md`: 게임 소개, 실행 방법, 조작 방법, 파일 구성을 정리한 문서입니다.
