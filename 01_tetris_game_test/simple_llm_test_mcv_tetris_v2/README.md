# Tetris - Atari 1988 Arcade Style

아타리(Atari Games, 1988년 아케이드판) 테트리스의 게임성과 그래픽을 재현한 HTML 기반 게임입니다.

## 파일 구성

- `index.html` - 메인 HTML 파일
- `style.css` - 스타일링 파일
- `game.js` - 게임 로직 파일

## 실행 방법

1. `index.html` 파일을 브라우저(Chrome, Firefox, Edge 등)로 직접 엽니다.
2. **ENTER** 키(데스크톱) 또는 게임 overlay에서 시작 버튼을 터치하여 게임을 시작합니다.

> 모바일 기기에서는 자동으로 터치 컨트롤 버튼이 표시됩니다.

## 조작법

### 키보드 (Desktop)

| 키 | 기능 |
|----|------|
| ← | 왼쪽으로 이동 |
| → | 오른쪽으로 이동 |
| ↑ | 회전 |
| ↓ | 부드러운-drop (점수 +1) |
| SPACE | 하드-drop (점수 +2 per row) |
| P | 일시정지/재개 |

### 터치 (Mobile)

| 버튼 | 기능 |
|------|------|
| ← | 왼쪽으로 이동 |
| → | 오른쪽으로 이동 |
| ↻ | 회전 |
| ↓ | 부드러운-drop (점수 +1) |
| DROP | 하드-drop (점수 +2 per row) |

## 게임 규칙

- 완성된 줄을 없애면 점수가 획득됩니다 (Atari 스코어링: 1줄=40, 2줄=100, 3줄=300, 4줄=1200)
- 10줄마다 레벨이 Up되며 속도가 빨라집니다
- 피스가 상단에 쌓여 이동할 수 없으면 Game Over
- Ghost Piece(음영)로 피스가落地하는 위치를 미리 확인할 수 있습니다
