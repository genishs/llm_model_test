# ATARI TETRIS

아타리(Atari Games, 1988년) 아케이드판 테트리스를 웹 브라우저에서 재현한 게임입니다.

## 📁 파일 구성

- `index.html` - 게임 파일 (단일 HTML 파일)
- `README.md` - 이 설명 파일

## ▶️ 실행 방법

1. `index.html` 파일을 더블 클릭하거나
2. 브라우저에 파일을 드래그 앤 드롭하거나
3. 명령어로 실행: `open index.html` (Mac) 또는 `start index.html` (Windows)

별도의 설치나 서버 설정 없이 바로 실행됩니다.

## 📱 모바일 터치 조작

모바일 기기에서는 자동으로 터치 조작 버튼이 표시됩니다.

| 조작 | 방법 |
|---|---|
| 이동 (좌/우) | 캔버스 왼쪽/오른쪽 영역 터치 후 드래그 |
| 회전 | 캔버스 중앙 영역 탭 또는 더블클릭 |
| 내리기 | 하단 내리기 버튼 탭 |
| 일시정지 | 하단 일시정지 버튼 탭 |

**터치 제스처:**
- **좌우 이동**: 캔버스 왼쪽 또는 오른쪽을 터치한 후 수평으로 드래그
- **회전**: 캔버스를 탭(한 번 클릭)하거나 더블클릭
- **빠르게 내리기**: 캔버스 아래쪽을 터치 후 수직으로 드래그
- **일시정지**: 하단 "일시정지" 버튼 탭

## 🎮 조작법 (키보드)

| 키 | 동작 |
|---|---|
| ← | 왼쪽 이동 |
| → | 오른쪽 이동 |
| ↓ | 빠르게 내리기 |
| ↑ | 블록 회전 |
| P | 일시정지/재개 |
| Q | 게임 종료 |

## 🎯 게임 설명

- **점수 시스템**: 1줄 제거 시 40점, 2줄 100점, 3줄 300점, 4줄 1200점 (레벨당 배수)
- **레벨업**: 10줄마다 레벨 상승, 블록 낙하 속도 증가
- **블록 종류**: I, J, L, O, S, T, Z (아타리 오리지널 색상)
- **Next 기능**: 다음 블록 미리 보기
