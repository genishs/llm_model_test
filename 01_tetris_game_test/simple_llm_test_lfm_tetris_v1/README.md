# Atari 스타일 테트리스

아타리(Atari) 아케이드 버전의 테트리스를 HTML만으로 구현한 웹 기반 게임입니다. 별도 설치나 빌드 없이 `index.html` 파일을 브라우저에서 바로 실행할 수 있습니다.

## 실행 방법

1. `index.html` 파일을 브라우저로 엽니다 (Chrome, Firefox, Edge 등).
2. 게임이 시작되며, 자동으로 조작됩니다.
3. `P` 키로 일시정지/재개, `R` 키로 초기화할 수 있습니다.

## 조작법

| 키 | 기능 |
|----|------|
| ← (왼쪽 화살표) | 피스 이동 |
| → (오른쪽 화살표) | 피스 이동 |
| ↓ (아래 화살표) | 피스 하강 |
| ↑ (위 화살표) | 피스 회전 |
| Space | 하드 드롭 (즉시 하강) |
| P | 일시정지 / 재개 |

## 게임 소개

- **아타리 스타일**: 1988년 아케이드판 테트리스의 그래픽과 게임성을 최대한 재현했습니다.
- **점수 시스템**: 라인 클리어 시 점수가 주어지며, 레벨이 올라갈수록 속도가 빨라집니다.
- **라이프 시스템**: 3개의 라이프가 있으며, 피스가 바닥에 닿으면 라이프가 하나 줄어듭니다.

## 참고 사항

- 모든 기능이 단일 HTML 파일에 포함되어 있어 별도 설치나 서버가 필요하지 않습니다.
- Atari 스타일의 픽셀 그래픽을 위해 Canvas를 사용했습니다.
