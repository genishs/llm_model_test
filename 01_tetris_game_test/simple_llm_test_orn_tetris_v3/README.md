# 아타리 테트리스 (Atari Tetris, 1988)

1988년 아타리(Atari Games) 아케이드판 테트리스의 게임성과 그래픽을 최대한
가깝게 재현한 웹 기반 테트리스 게임입니다.

별도 설치·빌드·서버 없이 `index.html` 파일을 브라우저로 열면 바로 실행됩니다.

## 재현한 요소

- **SRS(Super Rotation System) 회전 규칙**과 월 킥(Wall Kick)
- **7-bag 랜덤라이저** – 공평한 테트로미노 출현
- **고스트피스** – 떨어질 위치 표시
- **홀드 기능** – 현재 조각을 저장했다가 나중에 사용
- **NEXT 표시** – 나올 다음 미리보기
- **아타리 스코어링** – 1줄 100 / 2줄 300 / 3줄 500 / 4줄 800 (레벨 곱하기)
- **아케이드 레벨/크레딧/컨티뉴 시스템** – 아래 설명 참고
- **비네팁/베벨 처리된 블록 그래픽** – 클래식 아케이드 느낌

## 아케이드 시스템

### 레벨 (LEVEL)
- **10줄을 지운마다 레벨이 1 오릅니다.** (초기 레벨 1)
- 레벨이 오를수록 블록 낙하 속도가 빨라집니다.
  - 낙하 간격 = `max(50ms, 800ms - (레벨-1) × 70ms)`
  - 예: 레벨 1 → 800ms, 레벨 2 → 730ms, … 레벨 11 이상 → 50ms(최속)
- 화면 오른쪽 패널의 **LEVEL** 표시로 현재 레벨을 확인할 수 있습니다.

### 크레딧 (CREDITS) & 코인
- 시작 시 **크레딧 1**이 주어집니다.
- **코인 투입**으로 크레딧을 계속 쌓을 수 있습니다 (`N` 키 또는 `COIN` 버튼).
- 게임을 **시작하거나** (타itel 화면에서) **게임 오버 후 계속**하려면 크레딧이 필요합니다.
- 새 게임 시작 1회당 크레딧 1이 소모됩니다.
- 남은 크레딧은 화면 오른쪽 패널의 **CREDITS** 표시로 확인할 수 있습니다.

### 컨티뉴 (CONTINUE)
- 게임 오버 후 **10초 카운트다운**이 시작됩니다.
- 시간 안에 **계속(PRESS ENTER 또는 Enter)**하면 크레딧 1을 소모하고
  **점수·레벨·줄 수를 그대로 유지**한 채 게임을 이어갑니다.
- 시간 안에 이어하지 않으면 크레딧 소유와 무관하게 **타itel 화면**으로 돌아갑니다.
- 계속 중에도 **코인 투입(N / COIN)**으로 크레딧을 추가할 수 있습니다.

## 실행 방법

1. 이 폴더의 `index.html` 을 두 번 클릭하거나
2. 원하는 브라우저(Chrome, Edge, Firefox, Safari)에 파일을 드래그해 드롭하면
   즉시 실행됩니다.

추가적인 패키지, 빌드, 로컬 서버가 필요 없습니다.

## 조작법

### 키보드 (PC)

| 키 | 동작 |
| ---- | ---- |
| `←` `→` | 좌우 이동 |
| `↓` | 소프트 드롭 (천천히 내리기, 1점 추가) |
| `↑` 또는 `X` | 시계 방향 회전 |
| `Z` | 반시계 방향 회전 |
| `Space` | 하드 드롭 (즉시 낙하, 줄을 많이 지우면 보너스) |
| `C` | 홀드 (조작 저장) |
| `P` | 일시정지 / 계속 |
| `N` | 코인 투입 (크레딧 +1) |
| `Enter` | 시작 / 계속 / 재시작 |

### 터치 (모바일 / 태블릿)

터치 기기에서 화면 아래에 버튼이 자동으로 표시됩니다.

| 버튼 | 동작 |
| ---- | ---- |
| `◀` `▶` | 좌우 이동 |
| `▼` | 소프트 드롭 |
| `↻` / `↺` | 시계 / 반시계 방향 회전 |
| `DROP` | 하드 드롭 |
| `HOLD` | 홀드 |
| `PAUSE` | 일시정지 / 계속 |
| `START` | 시작 / 계속 / 재시작 |
| `COIN` | 코인 투입 (크레딧 +1) |

보드 위에서 손가락으로 스와이프해도 조작할 수 있습니다.

| 동작 | 방법 |
| ---- | ---- |
| 이동 | 좌우로 스와이프 |
| 소프트 드롭 | 아래로 스와이프 |
| 시계 회전 | 위로 빠르게 스와이프 (플릭) |
| 하드 드롭 | 화면을 두 번 탭 |

## 게임 흐름

아케이드 게임처럼 아래 순서로 끊김 없이 진행됩니다.

```
타itel(대기) → 시작 → 플레이 → 일시정지 → 게임 오버 → 컨티뉴 → 타itel → ...
```

- **타itel 화면**: 크레딧이 없으면 `INSERT COIN`이 표시됩니다.
  `N` 키 또는 `COIN` 버튼으로 코인을 넣어 크레딧을 쌓은 뒤 `START` / `Enter`로 시작합니다.
- **플레이**: 블록을 쌓아 줄을 지우면 점수·레벨이 올라갑니다. `P`로 일시정지.
- **게임 오버**: 블록이 상단까지 쌓이면 게임 오버와 함께 **10초 카운트다운**이 시작됩니다.
- **컨티뉴**: 카운트다운 중 `Enter`(또는 `START`)를 누르면 크레딧 1을 소모하고
  **점수·레벨·줄 수를 그대로 유지**한 채 이어집니다.
- **시간 초과**: 컨티뉴 시간(10초) 안에 이어하지 않으면 타itel 화면으로 돌아갑니다.
  (이때는 다시 코인 투입 `START`로 새 게임을 시작할 수 있습니다.)
