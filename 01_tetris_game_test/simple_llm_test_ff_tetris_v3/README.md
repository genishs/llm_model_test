# Atari Tetris (1988) — Web Recreation

브라우저에서 바로 실행되는 **HTML/JavaScript 기반 테트리스** 게임입니다.
1988년 아타리 게임즈(Atari Games) 아케이드판 *TETRIS*의 게임성과 그래픽(블록 비벨, 색상 팔레트, 점수 체계, 레벨별 낙하 속도 상승)을 최대한 가깝게 재현했습니다.

설치·빌드·로컬 서버 없이 `index.html` 파일만 열면 바로 플레이할 수 있습니다.

## 실행 방법

1. 이 폴더를 엽니다.
2. `index.html` 파일을 브라우저(Chrome, Edge, Firefox 등)로 드래그하거나 더블클릭해 엽니다.
3. 타이틀 화면에서 **코인(C)** 을 넣어 크레딧을 쌓고, **Enter**(PC) 또는 **START** 버튼(모바일)으로 게임을 시작합니다.

> 별도 의존성·외부 라이브러리·빌드 과정이 없습니다. 순수 HTML + CSS + JavaScript 단일 파일입니다.
> PC 브라우저뿐 아니라 스마트폰·태블릿 브라우저에서도 바로 실행되며, 터치 조작을 지원합니다.

## 아케이드 게임 흐름

타이틀(대기) → 시작 → 플레이 → 게임 오버 → 컨티뉴 → 타이틀 로 끊김 없이 이어집니다.

```
[타이틀/INSERT COIN] --코인→ 크레딧++ --START→ [플레이]
        ↑                                        |
        │                                    게임 오버
   시간 초과 / ESC                                ↓
        └───────────────  [컨티뉴 카운트다운] ←──┘
                              코인으로 이어하기 → 점수·레벨 유지한 채 계속
```

## 레벨 규칙

- **10줄**을 지울 때마다 레벨이 1씩 올라갑니다 (`level = floor(총 줄 수 / 10) + 1`).
- 레벨이 오를수록 **낙하 속도가 빨라집니다**: `간격(ms) = max(80, 1000 − (레벨−1)×90)` — 최대 레벨 11 이상에서는 80ms로 고정됩니다.
- 줄 점수에 레벨이 곱해져 고레벨일수록 점수가 크게 올라갑니다.
- 현재 레벨은 사이드 패널 **LEVEL**에 표시됩니다.

## 크레딧 · 코인 · 컨티뉴

아케이드 캐비닛처럼 코인을 넣어 크레딧을 쌓고, 크레딧을 소비해 플레이/컨티뉴합니다.

- **코인 투입**: 타이틀·게임오버(컨티뉴) 화면에서 `C` 키(PC) 또는 **COIN** 버튼(모바일)으로 크레딧 +1.
  (플레이 중에는 코인이 들어가지 않습니다.)
- **크레딧 소비**: 게임을 시작하거나 컨티뉴할 때마다 크레딧 1을 소모합니다. **크레딧이 0이면 시작/컨티뉴할 수 없습니다.**
- **크레딧 저장**: 남은 크레딧은 브라우저 `localStorage`에 저장되어 새로고침·재방문 후에도 유지됩니다.
- 사이드 패널 **CREDIT**에 남은 크레딧이 표시됩니다.

### 컨티뉴 (게임 오버 후)

- 게임 오버가 되면 **"CONTINUE?" 카운트다운(10초)** 화면이 나타납니다.
- 카운트다운 동안 코인을 넣어(`C` / COIN) **Enter** 또는 **START**를 누르면
  **점수·줄 수·레벨을 그대로 유지한 채** 같은 런(런 연속)으로 이어갑니다 (크레딧 1 소비).
- 시간(10초) 안에 이어하지 않거나 **ESC**를 누르면 타이틀 화면으로 돌아갑니다.

## 조작 방법

### 키보드 (PC)

| 키 | 동작 |
|----|------|
| `←` / `→` | 왼쪽 / 오른쪽 이동 |
| `↓` | 소프트 드롭 (빠른 낙하, 칸당 +1점) |
| `Z` | 반시계 방향 회전 |
| `X` | 시계 방향 회전 |
| `Space` | 하드 드롭 (즉시 착지, 칸당 +2점) |
| `P` | 일시정지 / 재개 |
| `C` | 코인 투입 (크레딧 +1) |
| `Enter` | 게임 시작 / 컨티뉴 |
| `Esc` | 컨티뉴 중단 후 타이틀로 |

### 터치 (모바일)

화면이 좁은 기기(폰)에서는 자동으로 아래 버튼 패드가 표시되고, 보드 크기도 화면에 맞춰 조정됩니다.

| 조작 | 동작 |
|------|------|
| `◀` / `▶` 버튼 | 왼쪽 / 오른쪽 이동 |
| `▼` 버튼 | 소프트 드롭 |
| `⟲` / `⟳` 버튼 | 반시계 / 시계 방향 회전 |
| `DROP` 버튼 | 하드 드롭 (즉시 착지) |
| `II` 버튼 | 일시정지 / 재개 |
| `COIN` 버튼 | 코인 투입 (크레딧 +1) |
| `START` 버튼 | 게임 시작 / 컨티뉴 |
| 보드 **스와이프**(좌우) | 조각 좌우 이동 |
| 보드 **탭** | 시계 방향 회전 |

> 버튼과 보드 제스처 모두 터치(`touchstart`)와 클릭을 지원하므로, 태블릿·터치 노트북에서도 그대로 동작합니다.

## 게임 특징 (Atari 1988 스타일)

- **테트로미노별 고유 색상** 팔레트 (I=청록, J=파랑, L=주황, O=노랑, S=초록, T=보라, Z=빨강)
- 블록에 **하이라이트/섀도 비벨**을 넣어 아케이드 특유의 입체감 재현
- 줄 완성 시 흰색 **점멸(flash)** 효과 후 라인 제거
- Classic 점수 체계: 1줄 400 / 2줄 800 / 3줄 1200 / 4줄(Tetris) 2000 × 레벨
- 10줄마다 **레벨 상승**, 레벨이 오를수록 낙하 속도 빨라짐 (현재 레벨 화면 표시)
- 아케이드 **코인 → 크레딧 → 컨티뉴** 시스템 (크레딧 localStorage 저장, 게임 오버 후 카운트다운 컨티뉴)
- 7개 조각을 섞어 뽑는 **백(bag) 시스템**으로 공정한 분포
- 다음 조각 미리보기(Next), 현재 점수/줄 수/레벨/크레딧 표시
