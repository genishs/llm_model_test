# ⚡ 아크 타워 디펜스 (Ark Tower Defense)

경로를 따라 이동하는 적들을 타워를 배치해 막는 **그리드 기반 타워 디펜스 게임**입니다.
4 종류의 타워와 5 종류의 적, 20개의 웨브를 완수해 살아남으세요.
**4·8·12·16·20 스테이지는 보스전**입니다.

## 🎮 실행 방법

별도의 설치·빌드·서버가 필요 없습니다.

1. `index.html` 파일을 웹 브라우저(Chrome, Edge, Firefox 등)로 엽니다.
2. 바로 플레이할 수 있습니다.

> 파일 더블클릭 또는 브라우저에 드래그&드롭하면 됩니다.

## 🧩 게임 규칙

- **라이프(Lives)**: 적이 목적지에 도달하면 -1. 0이지면 게임 오버.
- **골드(Gold)**: 적 처치 및 웨브 완료로 획득. 타워 건설·업그레이드에 사용.
- **웨이브(Wave)**: 20단계. **4의 배수(4·8·12·16·20)마다 보스전**이 열립니다.
- **타워 업그레이드**: 선택된 타워를 클릭하면 사거리 내적을 공격, 레벨당 피해 +50%. 최대 Lv.4.
- **승리**: 20 웨브를 모두 방어하면 승리.

## 👹 보스 규칙

**보스전은 4의 배수 스테이지(4·8·12·16·20)마다 열립니다.**
진행 중 사이드바에 현재 스테이지가 보스전인지와 보스 이름이 표시됩니다.

### 보스와 일반 적의 차이
| 구분 | 일반 적 | 보스 |
|------|---------|------|
| 체력 | 40~380 | 1400~2800 (스테이지별 상이) |
| 크기 | 작음 | 큼 (👹 아이콘) |
| 패턴 | 직선 이동 | **2페이즈 시스템** 보유 |
| 바 | 일반 체력바 | 이름 + 체력바 표시 |

### 4가지 보스
| 스테이지 | 보스 | 체력 | 특징 |
|---------|------|------|------|
| 4 | 🔥 불의 보스 발칸 | 1400 | 가장 약함, 시작 보스 |
| 8 | ❄️ 얼음 보스 프리제 | 1800 | 높은 체력 · 회복 |
| 12 | ⚡ 번개 보스 토르 | 2200 | 빠른 속도 · 회복 |
| 16 | 🪄 철의 보스 티탄 | 2800 | 가장 강한 보스 |

(그 후 반복: 20 스테이지는 다시 발칸)

### 보스 행동 패턴
- **1페이즈**: 일반적인 속도로 이동하며 공격합니다.
- **2페이즈**: 체력이 최대의 **50% 이하**로 내려지면 발동합니다.
  - **속도가 상승**합니다.
  - **매秒 일정 체력을 회복**합니다(회복량은 보스마다 다름).
- 따라서 2페이즈 전환 전에 최대한 데미지를 넣거나, 지속적인 공격으로 회복을 상쇄해야 합니다.

### 보스 표시
- 사이드바 "보스전" 항목에 현재 보스 이름 표시 (보스전 아닐 때는 숨겨짐).
- 게임 화면 상단에 보스 2페이즈 전환·보스 격파 배너 표시.
- 보스는 빨간 길 위에 큰 고리로 강조되어 표시됩니다.

## 🎨 디자인 노트

- 다크 테마 UI + Canvas 2D 렌더링.
- 모든 그래픽(타워, 적, 이펙트)은 Canvas 기본 도형·아이콘 이모지로 구현, 외부 에셋 없음.
- 파티클 이펙트로 공격·폭발·처치 연출.
- **모바일 대응**: 화면 크기에 따라 자동 크기 조절(responsive), 캔버스 `touch-action: none` 적용.

## 📄 출처 및 라이선스

- 외부 라이브러리, 이미지, 사운드 사용 없음.
- UI 아이콘 이모지는 사용하는 OS/브라우저의 표준 이모지(Unicode)를 그대로 표시합니다.
