**모바일 터치 지원 버전 - 보스전 추가**

웹 브라우저에서 바로 실행되는 AI/코딩 테마의 타워 디펜스 게임입니다.

## 🎮 게임 소개

"Simple LLM Defense"는 코드베이스를 방어하기 위한 디펜스 게임입니다.

- **테마**: AI/코딩 디펜스 - "버그 몬스터"와 "멀웨어 바이러스"를 막아라!
- **장르**: 타워 디펜스
- **플레이 시간**: 5-10분
- **난이도**: 초급~중급

## 🎯 게임 규칙

### 목표
- 12개의 웨이브를 견뎌내어 승리하세요!
- 생명을 모두 잃거나 웨이브를 모두 통과하면 게임 종료

### 스테이지 및 보스 전략
게임은 4개의 웨이브마다 스테이지가 변경되며, 매 4번째 웨이브(4, 8, 12 웨이브)에 보스전이 열립니다.

#### 스테이지 구성
- **스테이지 1**: 웨이브 1-4 (보스전 없음)
- **스테이지 2**: 웨이브 5-8 (보스전 없음)
- **스테이지 3**: 웨이브 9-12 (최종 보스전)

#### 보스전 규칙
- **보스출현**: 4, 8, 12 웨이브에 자동으로 보스 등장
- **보스 체력**: 스테이지당 500 + (스테이지 × 200) HP
  - 스테이지 1 보스: 700 HP
  - 스테이지 2 보스: 900 HP
  - 스테이지 3 보스: 1100 HP
- **보스 속도**: 1.5 (보통 속도)
- **보스 보상**: 500 Money
- **보스 특징**: 
  - 크기가 크고 (반지름 25px) 두꺼운 체력바 표시
  - 적이 빠져나갈 때 5의 추가 데미지 입힘
  - 진한 보라색 (#ff00ff) 외형, 테두리 있음

## 🎮 조작 방법

### 기본 조작
1. **방어기 선택**: 하단 UI에서 원하는 방어기를 클릭
2. **설치**: 맵 위의 빈 공간을 클릭하여 방어기 설치
3. **웨이브 시작**: "웨이브 시작" 버튼 클릭

### 커맨드 목록
- `방어기 선택` → 방어기 버튼 클릭
- `설치` → 맵 클릭 (경로 근처에는 설치 불가)
- `웨이브 시작` → 적 등장
- `일시정지` → 게임 멈춤
- `재개` → 게임 재개

### 설치 규칙
- 경로 근처 (40px 이내)에는 설치 불가
- 다른 방어기 근처 (50px 이내)에는 설치 불가
- 돈이 부족하면 설치 불가

## 📱 모바일 (터치) 조작

### 터치 기본 조작
1. **방어기 선택**: 터치로 방어기 버튼 탭
2. **설치 위치 지정**: 맵 위를 탭하여 설치 위치 선택
3. **설치 실행**: 설치 위치를 탭하여 방어기 설치
4. **웨이브 시작**: "웨이브 시작" 버튼 탭

### 터치 특징

- **터치 엔드**: 설치 위치를 탭하여 설치 완료
- **자동 크기 조정**: 모바일 화면에 자동으로 맞춤

### 모바일 최적화

## 🚀 실행 방법

### 데스크톱 실행
#### 방법 1: 파일 열기
1. `index.html` 파일을 더블 클릭
2. 웹 브라우저에서 게임 자동 실행

#### 방법 2: 드래그 앤 드롭
1. 브라우저 창 열기
2. `index.html` 파일을 브라우저에 드래그

### 모바일 실행
#### 방법 1: 웹 브라우저
1. `index.html` 파일을 모바일 기기로 전송
2. 파일을 탭하여 웹 브라우저로 열기
3. 게임 자동 실행 및 터치 조작 가능

#### 방법 2: 로컬 서버 (권장)
```bash
# Python 3
python3 -m http.server 8000

# Node.js
npx http-server

# PHP
php -S localhost:8000
```
모바일 브라우저에서 `http://[데스크톱-아이피]:8000` 접속

#### 방법 3: GitHub Pages (권장)
1. GitHub에 업로드
2. Settings > Pages > main branch 설정
3. URL 공유하여 모바일에서 접속
