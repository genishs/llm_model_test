# Neon Base Defense

## 게임 소개
`Neon Base Defense`는 네온 스타일의 디펜스 게임입니다. 아래에 위치한 기지를 방어하며 위에서 내려오는 적들을 격파하는 게임입니다. 적기가 기지에 도달하기 전에 사격하여 격파해야 하며, 적을 격파할 때마다 점수를 얻고 스테이지가 진행될수록 난이도가 증가합니다.

## 실행 방법
1. 이 폴더의 `index.html` 파일을 웹 브라우저(Chrome, Firefox, Safari 등)에서 엽니다.
2. 별도의 설치나 서버 구동 없이 바로 게임이 시작됩니다.

## 조작 방법
- **조준 및 이동 (데스크톱)**: 마우스를 왼쪽/오른쪽으로 움직이면 기지(파란 원)가 마우스 위치에 따라 수평으로 이동합니다.
- **조준 및 이동 (모바일)**: 화면에서 손가락을 왼쪽/오른쪽으로 드래그하면 기지가 수평으로 이동합니다.
- **사격**: 기지는 가장 가까운 적을 자동으로 조준하고 300ms 간격으로 자동 사격합니다.
- **게임 재시작**: 게임 오버 시 나타나는 'Restart' 버튼을 클릭하면 처음부터 다시 시작합니다.

## 게임 규칙
- 적(빨간/분홍 원)이 화면 상단에서 생성되어 하단으로 내려옵니다.
- 적을 격파할 때마다 10점의 점수를 얻습니다.
- 적이 화면 하단(기지 위치)에 도달하면 기지의 건강도(Health)가 1 감소합니다.
- 건강도가 0이 되면 게임 오버입니다.
- 점수가 100점, 200점, 300점...씩 누적될 때마다 스테이지(Stage)가 증가하며, 적 생성 간격이 짧아지고 적의 속도가 증가합니다.

## 스테이지 및 보스 규칙
- 스테이지는 점수가 100점씩 누적될 때마다 1 증가합니다 (100점=스테이지2, 200점=스테이지3, ...).
- **보스전**: 스테이지가 4의 배수일 때 (4, 8, 12, 16, ... 스테이지) 보스전이 발생합니다.
- 보스전 화면 상단에 "BOSS!" 표시가 나타납니다.
- 보스는 일반 적과 달리:
  - 더 큰 크기(반경 40)와 높은 체력(초기 30체력 + 스테이지*10)을 가집니다.
  - 보스 상단에 체력 바가 표시됩니다.
  - 보스는 화면 상단에서 내려온 후 좌우로 이동하는 패턴을 보입니다.
  - 보스를 격파할 때 100점 + (스테이지*20)의 점수를 얻습니다.
- 보스가 격파되거나 화면 하단에 도달하면 다음 스테이지로 진행됩니다.
