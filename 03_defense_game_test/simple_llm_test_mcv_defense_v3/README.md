# 🛡️ 简单防御游戏 (Simple Defense Game)

浏览器에서 바로 실행되는 타워 디펜스 게임입니다.

## 게임 소개

적들이 지정된 경로를 따라 움직여 끝점까지 도달하는 것을 막아내는 디펜스 게임입니다. 
塔(탑)를 설치하여 적을 공격하고, 파업마다 점점 강한 적들이 등장합니다.

## 스테이지·보스 규칙

- **보스전**: 4번째, 8번째, 12번째... 스테이지(파업)마다 보스전이 열립니다.
- **보스 특성**:
  - 일반 적보다 훨씬 높은 체력을 가집니다.
  - 보스는 빨간색 글씨로 "BOSS" 라벨이 표시됩니다.
  - 보스를 처치하면 100💰의 보상을 얻습니다.
  - 보스는 일반 적보다 느리게 움직입니다.
- 화면에서 현재 스테이지 번호와 보스전 여부 `(보스전)` 를 확인할 수 있습니다.

## 실행 방법

1. `index.html` 파일을 브라우저(Chrome, Firefox, Edge 등)로 직접_open_합니다.
2. 별도 설치나 빌드 과정이 필요 없습니다.

## 조작 방법

### PC (마우스)
- **탑 설치**: 아래 버튼에서탑 종류를 선택한 후, 게임 화면 클릭하여탑을 설치합니다.
  - 🔫 **기본탑** (50💰): 평균 성능, 빠른 사격 속도
  - 🎯 **狙击탑** (100💰): 긴 사거리, 높은损害, 느린 사격 속도
  - ❄️ **감속탑** (75💰): 적을 느리게 만드는 효과
- **파업 시작**: "下一波开始" 버튼을 클릭하여 다음 파업의 적을 보내줍니다.
- **게임 재시작**: 게임 종료 후 "重新游戏" 버튼으로 다시 시작합니다.

### 모바일 (터치)
- **탑 설치**: 아래 버튼에서탑 종류를 선택한 후, 게임 화면을 터치하여탑을 설치합니다.
- **파업 시작**: "下一波开始" 버튼을 터치하여 다음 파업의 적을 보내줍니다.
- **게임 재시작**: 게임 종료 후 "重新游戏" 버튼을 터치하여 다시 시작합니다.

> 모바일에서는 화면 크기에 맞게 게임이 자동 조정됩니다.

##注意事项

- 탑은 경로 근처에 설치할 수 없습니다(경로에서 최소 30px 이상 떨어져야 함).
- 탑 간에도 최소 40px 이상의 거리가 필요하며, 겹쳐서 설치할 수 없습니다.
- 적이 끝점까지 20번 도달하면 게임이 종료됩니다.

## 기술 스택

- HTML5 Canvas
- Vanilla JavaScript (외부 라이브러리 없음)
- CSS3

## 출처 및 라이선스

이 게임은 외부 라이브러리, 이미지, 사운드를 사용하지 않고 순수 HTML5/JavaScript로 구현되었습니다.

## 모바일 지원

- 터치 조작 지원 (touchstart 이벤트)
- 반응형 디자인 (화면 크기에 따라 canvas 자동 조정)
- 모바일 화면에 최적화된 UI 버튼 크기

## 스테이지·보스 규칙 (요약)

- 4, 8, 12, 16... 스테이지가 보스전
- 보스는 높은 체력, 빨간색 Glow 효과, "BOSS" 라벨持有
- 보스 처치 보상: 100💰
