# ⚡ 아크 타워 디펜스 (Ark Tower Defense)

경로를 따라 이동하는 적들을 타워를 배치해 막는 **그리드 기반 타워 디펜스 게임**입니다.
4 종류의 타워와 5 종류의 적, 20개의 웨브를 완수해 살아남으세요.

## 🎮 실행 방법

별도의 설치·빌드·서버가 필요 없습니다.

1. `index.html` 파일을 웹 브라우저(Chrome, Edge, Firefox 등)로 엽니다.
2. 바로 플레이할 수 있습니다.

> 파일 더블클릭 또는 브라우저에 드래그&드롭하면 됩니다.

## 🧩 게임 규칙

- **라이프(Lives)**: 적이 목적지에 도달하면 -1. 0이지면 게임 오버.
- **골드(Gold)**: 적 처치 및 웨브 완료로 획득. 타워 건설·업그레이드에 사용.
- **웨이브(Wave)**: 20단계. 5의 배수마다 보스(거인)가 등장.
- **타워 업그레이드**: 선택된 타워를 클릭하면 사거리 내적을 공격, 레벨당 피해 +50%. 최대 Lv.4.
- **승리**: 20 웨브를 모두 방어하면 승리.

## 🎨 디자인 노트

- 다크 테마 UI + Canvas 2D 렌더링.
- 모든 그래픽(타워, 적, 이펙트)은 Canvas 기본 도형·아이콘 이모지로 구현, 외부 에셋 없음.
- 파티클 이펙트로 공격·폭발·처치 연출.
- **모바일 대응**: 화면 크기에 따라 자동 크기 조절(responsive), 캔버스 `touch-action: none` 적용.

## 📄 출처 및 라이선스

- 외부 라이브러리, 이미지, 사운드 사용 없음.
- UI 아이콘 이모지는 사용하는 OS/브라우저의 표준 이모지(Unicode)를 그대로 표시합니다.
