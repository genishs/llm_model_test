# NEON CORE DEFENSE

네온 사이버펑크 스타일의 **토션 디펜스(Tower Defense)** 웹 게임입니다.
브라우저에서 열리는 단일 HTML 파일 하나로 동작하며, 별도 설치·빌드·서버가 필요 없습니다.

## 게임 소개

네온 그리드 너머로 무수한 **해커 드론**이 접근해 왔다.
중앙 우측에 위치한 **코어(CORE)** 를 지켜라.

- 드론들은 화면 왼쪽에서 시작해 꺾여진 **네온 경로**를 따라 코어로 이동한다.
- 경로 주변의 빈 공간에 **터렛**을 배치해 드론을 격파한다.
- 드론을 처치하면 **골드(◈)** 를 획득하고, 터렛을 **업그레이드**하거나 **철거**할 수 있다.
- 웨이브가 진행될수록 적의 체력·속도·수가 증가하며, **5의 배수 웨이브**에는 보스가 등장한다.
- 코어의 체력이 0이 되면 게임 오버.

### 목표
- 가능한 한 많은 웨이브를 버텨내라. (스코어 = 도달한 최대 웨이브)

## 실행 방법

1. `index.html` 파일을 더블클릭 (또는 브라우저로 열기).
2. `START` 버튼을 누른다.
3. 약 1초 후 1 웨이브가 자동으로 시작된다.

> 인터넷 연결이 필요 없습니다. 모든 로직·그래픽·UI가 파일 안에 인라인으로 포함되어 있습니다.

## 조작 방법

| 입력 | 동작 |
|------|------|
| **좌클릭** (하단 터렛 버튼) | 배치할 터렛 종류 선택 / 다시 누르면 해제 |
| **좌클릭** (맵) | 선택한 터렛 배치 · 이미 지어진 터렛은 선택(업그레이드 패널 열림) |
| **우클릭** / **Esc** | 배치 모드 취소 · 선택 해제 |
| **Space** | 다음 웨이브 조기 시작 |

### 터렛 종류

| 이름 | 비용 | 특징 |
|------|------|------|
| **PULSE** (청) | ◈ 50 | 균형형 레이저. 사거리·속도 균형. |
| **FLAK** (주황) | ◈ 90 | 짧은 사거리, 높은 피해, 빠른 발사. |
| **RAIL** (보라) | ◈ 160 | 긴 사거리, 단일 고데미지 궤도포. |

- **업그레이드**: 터렛을 선택하면 패널이 열림. 최대 5레벨까지 데미지·사거리 증가.
- **철거**: 배치 비용의 60% 환불.

### 적 종류

| 이름 | 특징 |
|------|------|
| Grunt (빨강 삼각형) | 기본형, 중간 체력/속도 |
| Runner (노랑 마름모) | 빠르지만 약함 |
| Tank (보라 육각형) | 느리지만 단단 |
| Boss (분홍 팔각형) | 5의 배수 웨이브, 매우 단단 |

`index.html` 하나면 충분합니다. 외부 라이브러리·이미지·소리를 사용하지 않았습니다.

## 기술 구성

- 순수 **HTML5 Canvas + Vanilla JavaScript** (ES2017, `"use strict"`)
- 의존성 없음 (no dependencies)
- 고정 시간보정(delta time) 게임 루프, `requestAnimationFrame`
- 반응형: 창 크기에 따라 경로·그리드 자동 재계산
- 파티클, 글로우(shadowBlur), 화면 진동(shake) 등 시네마틱 효과

## 출처 / 라이선스

- **외부 라이브러리·이미지·소리: 없음.** 모든 코드는 본 작업에서 직접 작성했습니다.
- 사용된 글꼴: 시스템 기본 폰트(`Segoe UI`, `Malgun Gothic`).
- 따라서 별도 라이선스 표시가 요구되지 않습니다.

## 밸런스 메모 (개발 노트)

- 웨이브 n 적 체력 배율 `1 + (n-1)*0.22`, 속도 배율 `1 + (n-1)*0.03`
- 웨이브 클리어 보너스 `20 + n*5` 골드
- 코어 피해: 일반 6 / 탱크 12 / 보스 30
- 터렛 5레벨까지, 레벨당 데미지 ×1.45, 사거리 ×1.1, 발사 간격 ×0.92
