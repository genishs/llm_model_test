# 🛡️ 简单防御游戏 (Simple Defense Game)

浏览器에서 바로 실행되는 타워 디펜스 게임입니다.

## 게임 소개

적들이 지정된 경로를 따라 움직여 끝점까지 도달하는 것을 막아내는 디펜스 게임입니다. 
塔(탑)를 설치하여 적을 공격하고, 파업마다 점점-strong한 적들이 등장합니다.

## 실행 방법

1. `index.html` 파일을 브라우저(Chrome, Firefox, Edge 등)로 직접_open_합니다.
2. 별도 설치나 빌드 과정이 필요 없습니다.

## 조작 방법

- **탑 설치**: 아래 버튼에서탑 종류를 선택한 후, 게임 화면 клик하여탑을 설치합니다.
  - 🔫 **기본탑** (50💰): 평균 성능, 빠른 사격 속도
  - 🎯 **狙击탑** (100💰): 긴 사거리, 높은损害, 느린 사격 속도
  - ❄️ **감속탑** (75💰): 적을 느리게 만드는 효과
- **파업 시작**: "下一波开始" 버튼을 클릭하여 다음 파업의 적을 보내줍니다.
- **게임 재시작**: 게임 종료 후 "重新游戏" 버튼으로 다시 시작합니다.

##注意事项

- 탑은 경로 근처에 설치할 수 없습니다(경로에서 최소 30px 이상 떨어져야 함).
- 탑 간에도 최소 40px 이상의 거리가 필요하며, 겹쳐서 설치할 수 없습니다.
- 적이 끝점까지 20번 도달하면 게임이 종료됩니다.
