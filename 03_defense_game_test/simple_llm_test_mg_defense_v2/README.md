# MG Defense - 브라우저 타워 디펜스

## 게임 소개
간단한 2D 타워 디펜스. 경로를 따라 오는 적을 타워로 막아 생명 유지.

## 실행 방법
index.html 을 브라우저에서 열기. 별도 설치 불필요.

## 조작법
- 상단 버튼으로 타워 선택: 대포 50G / 레이저 80G / 스나이퍼 120G
- 캔버스에서 클릭하여 타워 배치 (경로 위는 불가)
- 적 처치 시 골드 획득, 파도 진행
- 생명 0 이면 게임 오버

## 모바일 터치 조작
- 화면 상단 타워 버튼을 터치하여 선택
- 게임 화면을 터치하면 해당 위치에 타워가 배치됩니다. 경로 위 터치는 무시됩니다.
- 화면이 자동으로 기기 크기에 맞춰 확대/축소됩니다. 가로/세로 모드 모두 지원.
- 터치 시 스크롤이 발생하지 않도록 최적화되었습니다.
