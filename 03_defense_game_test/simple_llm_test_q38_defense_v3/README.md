# NEON CORE DEFENSE

네온 사이버펑크 스타일의 **토션 디펜스(Tower Defense)** 웹 게임입니다.
브라우저에서 열리는 단일 HTML 파일 하나로 동작하며, 별도 설치·빌드·서버가 필요 없습니다.

## 게임 소개

네온 그리드 너머로 무수한 **해커 드론**이 접근해 왔다.
중앙 우측에 위치한 **코어(CORE)** 를 지켜라.

- 드론들은 화면 왼쪽에서 시작해 꺾여진 **네온 경로**를 따라 코어로 이동한다.
- 경로 주변의 빈 공간에 **터렛**을 배치해 드론을 격파한다.
- 드론을 처치하면 **골드(◈)** 를 획득하고, 터렛을 **업그레이드**하거나 **철거**할 수 있다.
- **스테이지(웨이브)** 가 진행될수록 적의 체력·속도·수가 증가한다.
- **4의 배수 스테이지(4·8·12·16…)에는 보스전**이 열린다.
- 코어의 체력이 0이 되면 게임 오버.

### 목표
- 가능한 한 많은 웨이브를 버텨내라. (스코어 = 도달한 최대 웨이브)

## 실행 방법

1. `index.html` 파일을 더블클릭 (또는 브라우저로 열기).
2. `START` 버튼을 누른다.
3. 약 1초 후 1 웨이브가 자동으로 시작된다.

> 인터넷 연결이 필요 없습니다. 모든 로직·그래픽·UI가 파일 안에 인라인으로 포함되어 있습니다.

## 조작 방법

### PC (마우스 + 키보드)

| 입력 | 동작 |
|------|------|
| **좌클릭** (하단 터렛 버튼) | 배치할 터렛 종류 선택 / 다시 누르면 해제 |
| **좌클릭** (맵) | 선택한 터렛 배치 · 이미 지어진 터렛은 선택(업그레이드 패널 열림) |
| **우클릭** / **Esc** | 배치 모드 취소 · 선택 해제 |
| **Space** | 다음 웨이브 조기 시작 |

### 모바일 (터치) — 휴대폰에서 그대로 플레이 가능

| 입력 | 동작 |
|------|------|
| **탭** (하단 터렛 버튼) | 배치할 터렛 종류 선택 / 다시 탭하면 해제 |
| **탭** (맵) | 선택한 터렛 배치 · 이미 지어진 터렛은 선택(업그레이드 패널 열림) |
| **길게 누르기** (0.5초, 지도 위) | 배치 모드 취소 · 선택 해제 (PC 우클릭 대체) |
| **▶ START WAVE** 버튼 | 다음 웨이브 조기 시작 (PC Space 대체) |

- **화면 회전 대응**: 세로(portrait)·가로(landscape) 모두 자동 대응. 회전하면 경로·그리드가 재계산됩니다.
- **화면 최적화**: 좁은 화면에서는 경로가 자동으로 간결해지고, 터렛 사거리·UI가 화면 크기에 맞춰 조절됩니다.
- **노치/베젤 대응**: `safe-area-inset`으로 상단·하단 UI가 화면 모서리에 묻히지 않습니다.
- **오동작 방지**: 더블탭 줌, 장악 스크롤, 컨텍스트 메뉴가 차단되어 조작이 정확합니다.
- 모바일에서는 지도 상단에 `탭: 배치/선택 · 길게 누르기: 취소` 힌트가 잠시 표시됩니다.

### 터렛 종류

| 이름 | 비용 | 특징 |
|------|------|------|
| **PULSE** (청) | ◈ 50 | 균형형 레이저. 사거리·속도 균형. |
| **FLAK** (주황) | ◈ 90 | 짧은 사거리, 높은 피해, 빠른 발사. |
| **RAIL** (보라) | ◈ 160 | 긴 사거리, 단일 고데미지 궤도포. |

- **업그레이드**: 터렛을 선택하면 패널이 열림. 최대 5레벨까지 데미지·사거리 증가.
- **철거**: 배치 비용의 60% 환불.

### 적 종류

| 이름 | 특징 |
|------|------|
| Grunt (빨강 삼각형) | 기본형, 중간 체력/속도 |
| Runner (노랑 마름모) | 빠르지만 약함 |
| Tank (보라 육각형) | 느리지만 단단 |
| **Boss (보스전 전용)** | 4의 배수 스테이지, 전용 패턴·고체력 (아래 참고) |

## 스테이지 & 보스 규칙

- **스테이지** = 웨이브 번호. 화면 상단 왼쪽에 `STAGE n` 배지가 항상 표시된다.
- **보스전**: **4의 배수 스테이지**(4, 8, 12, 16, …)에 열리며, 그 스테이지에는 일반 적 대신 **단일 보스 1기**만 등장한다.
- 보스전 중에는 화면 상단에 **깜빡이는 `⚠ BOSS — 이름 ⚠` 배지**와 **보스 체력 게이지(상단 중앙)** 가 표시된다.

### 보스 등급(티어) — 스테이지가 올라갈수록 강화

| 스테이지 | 보스 | 색상 | 코어 피해 | 보스 패턴 |
|---|---|---|---|---|
| 4 | **WARDEN** | 분홍 | 25 | 느리게 전진 + 주기적 **대시(2.4x 돌진)** |
| 8 | **EXECUTOR** | 보라 | 35 | 대시 + **그런트 소환** (최대 26기 제한) |
| 12 | **SINGULARITY** | 청록 | 45 | 대시 + 소환 (더 자주, 더 많이) |
| 16+ | **OVERMIND** | 주황 | 60 | 대시 + 소환 + **체력 35% 이하 시 분노(가속)** |

- **체력**: 기본 700 × 스테이지 스케일 `1+(n-1)*0.22` × 티어 배율 `1+(티어-1)*1.6` → 스테이지·티어가 오를수록 크게 증가.
- **속도**: `(30 + 티어*4)` × 스테이지 스케일. 대시 구간 동안 2.4배 가속(0.9초). OVERMIND는 분노 시 1.6~3.2배.
- **상승**: 보스 처치 시 티어별 고보상 골드(150/300/500/800).
- **코어 피해**: 보스가 코어에 닿으면 티어별 고정 피해(25/35/45/60)를 입힌다.

> 보스전의 핵심은 **대시 타이밍**에 맞춰 장사거리 터렛(RAIL)으로 집중 공격하고, 소환된 민병을 처리하는 것이다.

## 기술 구성

- 순수 **HTML5 Canvas + Vanilla JavaScript** (ES2017, `"use strict"`)
- 의존성 없음 (no dependencies)
- 고정 시간보정(delta time) 게임 루프, `requestAnimationFrame`
- 반응형: 창 크기에 따라 경로·그리드 자동 재계산
- 파티클, 글로우(shadowBlur), 화면 진동(shake) 등 시네마틱 효과
- **모바일 대응**: 터치 입력(탭/롱프레스), 화면 회전 대응, `viewport-fit` + `safe-area-inset`, `touch-action: none`, 시크리틱 클릭 차단, 반응형 UI(미디어쿼리), 화면 크기에 따른 사거리/크기 스케일링, 진동 피드백(`navigator.vibrate`)

## 출처 / 라이선스

- **외부 라이브러리·이미지·소리: 없음.** 모든 코드는 본 작업에서 직접 작성했습니다.
- 사용된 글꼴: 시스템 기본 폰트(`Segoe UI`, `Malgun Gothic`).
- 따라서 별도 라이선스 표시가 요구되지 않습니다.

## 밸런스 메모 (개발 노트)

- 웨이브(스테이지) n 적 체력 배율 `1 + (n-1)*0.22`, 속도 배율 `1 + (n-1)*0.03`
- 웨이브 클리어 보너스 `20 + n*5` 골드
- 코어 피해: 일반 6 / 탱크 12 / 보스 25~60 (티어별)
- 터렛 5레벨까지, 레벨당 데미지 ×1.45, 사거리 ×1.1, 발사 간격 ×0.92
- 보스: 4의 배수 스테이지, 체력 `700 * 스테이지스케일 * (1+(티어-1)*1.6)`, 대시 2.4x, 티어≥2 소환, 티어4 분노
