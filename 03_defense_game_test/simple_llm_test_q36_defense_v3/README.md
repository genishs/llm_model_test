# 🏰 성벽 방어작전 (Tower Defense)

Canvas 기반 브라우저 디펜스 게임. 별도의 설치나 빌드 없이 브라우저에서 바로 실행할 수 있습니다.

## 게임 소개

적들이 성벽을 향해 접근합니다! 다양한 터렛을 전략적으로 배치하여 적들을 막아내고 성벽을 지켜내세요.

### 세계관
마법 세계 '아크디아'에서, 어둠의 군단이 성벽을 향해 진군합니다. 당신은 성의 지휘관으로서 터렛 병영을 지휘하여 왕국을 지켜야 합니다.

### 장르
- ** tür**: 실시간 전략 디펜스 (Real-time Strategy Tower Defense)
- ** 목적**: 20개의 Wave를 모두 클리어하여 성벽을 방어
- ** 난이도**: Wave가 진행될수록 적의 체력/수량이 증가

## 파일 구성

```
├── index.html    # 메인 HTML 파일 (게임 화면)
├── style.css     # 스타일 시트
├── game.js       # 게임 로직 (Canvas API 사용)
└── README.md     # 이 파일
```

## 실행 방법

1. `index.html` 파일을 웹 브라우저에서 엽니다
2. "게임 시작" 버튼 클릭
3. 아래 패널에서 터렛을 선택 후 맵에 배치
4. "Wave 시작" 버튼으로 적을 보냄

> **추천 브라우저**: Chrome, Firefox, Edge (최신 버전)
>
> **모바일 지원**: iOS Safari, Android Chrome에서 최적화됨

## 모바일 대응 사항

- **반응형 캔버스**: 화면 크기에 따라 게임 맵이 자동으로 조정됩니다
- **터치 최적화**: 모든 버튼과 패널이 44px 이상 터치 타겟을 보장합니다
- **제스처 지원**: 탭 1회로 터렛 배치 (복잡한 제스처 불필요)
- **가로/세로 모드**: 모든 화면 방향을 지원합니다

## 적 종류

| 적 | 특징 |
|------|------|
| **일반** 🟠 | 기본 적, 표준 속도와 체력 |
| **패스트** 🟣 | 빠르지만 체력이 낮음 |
| ** 탱커** 🔴 | 느리지만 체력이 매우 높음 |
| **보스** 🐉 | 4의 배수 Wave마다 등장, 고유 특수 능력 보유 |

## 스테이지·보스 규칙

### 스테이지 구성

- 총 **20개의 Wave**로 구성됩니다
- **매 4번째 Wave(4, 8, 12, 16, 20)**가 보스전입니다
- 일반 Wave에는 일반/패스트/탱커 적이 혼합되어 출현합니다
- 보스 Wave에는 보스 + 소수의 일반 적이 출현합니다
- 보스 Wave 클리어 시 추가 골드 보너스를 받습니다

### 보스 전사 목록

| Wave | 보스 이름 | 특수 능력 | 설명 |
|------|----------|----------|------|
| **4** | 🔥 용왕 발칸 | 근접돌진 | 체력이 50% 이하가 되면 속도가 2.5배로 늘어나며 돌진합니다 |
| **8** | ☠️ 독룡 모스 | 독포 | 주기적으로 독을 뿌려 주변 적에게 피해와 독 효과를 줍니다 |
| **12** | 💎 수호석룡 | 방어구사 | 체력이 60% 이하가 되면 방어력을 높여 피해의 절반만 받습니다 (4초 간) |
| **16** | ⚡ 전기룡 젬 | 낙뢰 | 주기적으로 주변에 전기 폭격을 가해 적을 감속시키고 피해를 줍니다 |
| **20** | 👑 흑룡 킹도스 | 전기술구사 | 위 4가지 모든 기술을 사용합니다. 최종 보스! |

### 보스 특수 능력 상세

#### 🔥 근접돌진 (Wave 4)
- 체력 50% 이하 발동
- 3초마다 재차지
- 돌진 중 속도 2.5배 증가, 2초간 지속

#### ☠️ 독포 (Wave 8)
- 2.5초마다 자동 발동
- 주변 적에게 독 데미지 적용
- 3초간 독 효과 지속

#### 🛡️ 방어구사 (Wave 12)
- 체력 60% 이하 발동
- 5초마다 재차지
- 4초간 모든 피해의 50% 감소

#### ⚡ 낙뢰 (Wave 16)
- 2초마다 자동 발동
- 보스 주변 80範圍에 전기 폭격
- 적에게 데미지 + 1초 감속

#### 👑 전기술구사 (Wave 20)
- 위 모든 기술을 순차적으로 사용
- 각 기술의 재차지 시간이 약간 늘어난 대신 데미지가 더 큼
- 흑룡 킹도스를 처치하면 승리!

### 보스 UI 표시

- **헤더**: 보스 Wave에서는 Wave 숫자에 👑 이모지가 표시되고 붉은색으로 강조됩니다
- **캔버스 하단**: "👑 BOSS WAVE" 텍스트로 현재 보스전 여부 확인 가능
- **보스 체력바**: 보스 위에 이름 + 체력 수치 표시
- **상태 이모지**: 🛡️(방어구), ☠️(독), ⚡(돌진)으로 현재 활성화된 능력 확인 가능
