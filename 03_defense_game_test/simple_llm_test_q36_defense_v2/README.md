# 🏰 성벽 방어작전 (Tower Defense)

Canvas 기반 브라우저 디펜스 게임. 별도의 설치나 빌드 없이 브라우저에서 바로 실행할 수 있습니다.

## 게임 소개

적들이 성벽을 향해 접근합니다! 다양한 터렛을 전략적으로 배치하여 적들을 막아내고 성벽을 지켜내세요.

### 세계관
마법 세계 '아크디아'에서, 어둠의 군단이 성벽을 향해 진군합니다. 당신은 성의 지휘관으로서 터렛 병영을 지휘하여 왕국을 지켜야 합니다.

### 장르
- ** tür**: 실시간 전략 디펜스 (Real-time Strategy Tower Defense)
- ** 목적**: 20개의 Wave를 모두 클리어하여 성벽을 방어
- ** 난이도**: Wave가 진행될수록 적의 체력/수량이 증가

## 파일 구성

```
├── index.html    # 메인 HTML 파일 (게임 화면)
├── style.css     # 스타일 시트
├── game.js       # 게임 로직 (Canvas API 사용)
└── README.md     # 이 파일
```

## 실행 방법

1. `index.html` 파일을 웹 브라우저에서 엽니다
2. "게임 시작" 버튼 클릭
3. 아래 패널에서 터렛을 선택 후 맵에 배치
4. "Wave 시작" 버튼으로 적을 보냄

> **추천 브라우저**: Chrome, Firefox, Edge (최신 버전)
>
> **모바일 지원**: iOS Safari, Android Chrome에서 최적화됨

## 모바일 대응 사항

- **반응형 캔버스**: 화면 크기에 따라 게임 맵이 자동으로 조정됩니다
- **터치 최적화**: 모든 버튼과 패널이 44px 이상 터치 타겟을 보장합니다
- **제스처 지원**: 탭 1회로 터렛 배치 (복잡한 제스처 불필요)
- **가로/세로 모드**: 모든 화면 방향을 지원합니다

## 조작법

### PC (마우스)

| 조작 | 설명 |
|------|------|
| **터렛 선택** | 하단 패널에서 터렛 타입 클릭 |
| **터렛 배치** | 맵의 초록색 빈 공간 클릭 (파란색 길 위에는 불가) |
| **Wave 시작** | 상단 "Wave 시작" 버튼 클릭 |

### 모바일 (터치)

| 조작 | 설명 |
|------|------|
| **터렛 선택** | 하단 패널에서 터렛 타입 탭 |
| **터렛 배치** | 맵에서 터렛을 배치할 위치를 탭 |
| **Wave 시작** | 상단 "Wave 시작" 버튼 탭 |

> **참고**: 모바일에서는 맵을 탭하여 터렛을 배치합니다. PC와 동일한 게임play를 제공합니다.

## 터렛 종류

| 터렛 | 비용 | 특징 |
|------|------|------|
| **기본 터렛** 💙 | 50gold | 균형잡힌 성능, 표준 공격 |
| **저격터렛** ❤️ | 100gold | 긴 사거리, 높은 피해 |
| **감속 터렛** 💚 | 75gold | 적을 감속시킴 |
| **폭발 터렛** 💛 | 150gold | 범위 피해 (스플래시) |

## 적 종류

| 적 | 특징 |
|------|------|
| **일반** 🟠 | 기본 적, 표준 속도와 체력 |
| **패스트** 🟣 | 빠르지만 체력이 낮음 |
| ** 탱커** 🔴 | 느리지만 체력이 매우 높음 |
| **보스** 🔴 | 5의 배수 Wave마다 등장, 매우 높음 체력 |

## 게임 규칙

1. **골드**: 적을 처치하면 골드 획득 + Wave 클리어 시 보너스
2. **생명**: 적이 성벽(🏰)에 도달하면 생명 감소 (0이 되면 게임 오버)
3. **Wave**: 20단계 진행, 매 Wave마다 적의 수/강도 증가
4. **승리**: 20개의 Wave를 모두 클리어하면 승리

## 기술 스택

- **HTML5 Canvas** - 게임 렌더링
- **Vanilla JavaScript** - 게임 로직 (프레임워크 없음)
- **CSS3** - UI 스타일링
