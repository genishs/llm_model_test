# Simple Defense

## 게임 소개
- **장르**: 타워 디펜스 / 슈팅 (Top-down)
- **세계관**: 우주 전선에서 외계 침략자를 막는 방어 작전
- **규칙**: 플레이어는 화면 하단의 선박을 조작하여 위에서 떨어지는 적을 쏘아 제거한다. 적이 바닥에 도달하거나 선박을 뚫고 들어오면 게임 오버.
- **화면 구성**: 480x640 캔버스, 플레이어(녹색 사각형), 적(빨간색 사각형), 총알(노란색 사각형), 점수 표시
- **조작 방식**: 좌/우 화살표 또는 A/D 키로 이동, 스페이스바로 발사

## 실행 방법
- `index.html` 파일을 브라우저에서 바로 열면 게임이 시작됩니다. 별도의 설치나 빌드가 필요하지 않습니다.
- 게임이 끝나면 `R` 키를 눌러 재시작할 수 있습니다.

## 조작법
| 동작 | 키 / 터치 |
|------|-----------|----------|
| 이동 | ← → 화살표 또는 A D / 화면 하단 좌/우 버튼 |
| 발사 | Space 또는 화면 하단 중앙 발사 버튼 |
| 재시작 | R (게임 오버 시) |

## 파일 구성
- `index.html` – 게임 소스 코드 (HTML + JavaScript, 캔버스 기반)
- `README.md` – 이 문서

## 참고사항
- 외부 라이브러리나 이미지, 사운드 없이 순수 HTML5/JavaScript로 구현되었습니다.
- 모든 자산은 코드 내에 내장되어 있어 별도의 리소스 파일이 필요하지 않습니다.

## 스테이지 및 보스 규칙
- 게임은 4단계마다 보스전이 발생합니다. (예: 4·8·12 스테이지에서 보스전)
- 스테이지는 1부터 시작하며, 각 단계마다 일반 적이 무작위로 생성됩니다.
- 보스는 일반 적과 다른 체력(5 HP)과 행동(빠른 하강, 위로 총격)을 가집니다.
- 보스가 등장하면 화면 상단에 `Boss Fight!` 메시지와 현재 스테이지 번호가 표시됩니다.
- 보스가 패배하면 점수가 추가로 획득되며, 다음 단계로 진행됩니다.
- 보스전 여부는 화면에서 항상 확인할 수 있습니다.
