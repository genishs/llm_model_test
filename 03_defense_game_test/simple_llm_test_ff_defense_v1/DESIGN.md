# Frostline Defense — 기획 · 디자인 문서

## 1. 장르 해석
- 타워 디펜스(Tower Defense): 고정 경로로 밀려오는 적 웨이브를, 사전에 설치한 방어 유닛으로 저지하는 실시간 전략 게임.
- 플레이어 자원은 **골드**, 방어선은 **생명력(핵 HP)**, 진행 단위는 **웨이브**.

## 2. 세계관
최북단 관문 '프로스트라인'. 빙하 아래에서 깨어난 균열 생물(Cracklings)이 핵 격리炉를 노리고 빙하 길을 따라 밀려온다.
생존자 엔지니어인 플레이어는 냉각·전격·화염 세 종류의 프로토콜 타워로 마지막 관문을 지킨다.

## 3. 규칙

### 맵
- 20 x 12 격자 (셀 40px → 800x480 캔버스).
- 미리 정해진 단일 경로(웨이포인트)가 있으며, 경로를 제외한 셀에 타워 설치.
- 경로 셀·이미 설치된 셀·격자 밖은 설치 불가.

### 자원
- 시작 골드 220, 핵 HP 20.
- 적 처치 시 골드 획득, 웨이브 클리어 보너스 = 40 + wave*6.
- 타워 판매 시 투자금의 70% 환불.

### 타워 (3종)
| 이름 | 비용 | 피해 | 사거리 | 공격속도 | 특수 |
|---|---|---|---|---|---|
| Frost Coil (냉각) | 60 | 8 | 2.4셀 | 느림 | 45% 슬로우 1.6초 |
| Arc Node (전격) | 95 | 26 | 3.0셀 | 중간 | 관통(최대 3체, 감쇠 55%) |
| Ember Mortar (화염) | 130 | 40 AoE | 3.6셀 | 매우 느림 | 반경 0.9셀 폭발 |

- 업그레이드: Lv1→2→3, 비용 = 기본비용 * 0.8 * 현재Lv, 피해 x1.7, 사거리 +0.35셀, 공격속도 +18%.
- 최대 레벨 3.

### 적 (Cracklings)
| 종류 | HP | 속도 | 골드 | 특징 |
|---|---|---|---|---|
| Crawler | 낮음 | 중간 | 6 | 기본 |
| Runner | 매우 낮음 | 빠름 | 4 | 슬로우 내성 없음(회피 없음) |
| Brute | 높음 | 느림 | 18 | 슬로우 저항 40% |
| Warden | 매우 높음 | 매우 느림 | 35 | 슬로우 저항 70%, 보스급 |

- 웨이브가 오를수록 HP 배수 증가: hp * (1 + 0.22*(wave-1))
- 적 경로 도달 시 핵 HP -1 (Warden은 -3).

### 웨이브
- 총 25웨이브, 클리어 시 승리.
- 각 웨이브는 조합된 스폰 큐(지연 포함)로 구성, 이후 6초 준비 시간.
- 자동 다음 웨이브 / 수동 조기 시작 보너스 골드 = 남은 준비시간 * 2.

### 속도/배틀
- 게임 배속 x1 / x2 버튼.
- 공격은 투사체(탄환/광선/포탄)로 시각화.

## 4. 화면 구성
```
┌────────────── HUD: Wave / Gold / Core HP / Speed / Start ──────────────┐
│                                        │  사이드 패널                    │
│          Canvas 800x480                │  - 타워 구매 카드 3종          │
│   격자 + 경로 + 타워 + 적 + 투사체     │  - 선택된 타워 정보/업그레이드 │
│   마우스 미리보기(반투명 사거리 원)    │     /판매                      │
│                                        │  - 로그/메시지                 │
└─────────────────────────────────────────────────────────────────────────┘
```

## 5. 조작 방식
- 클릭: 빈 셀 = 선택한 타워 설치 / 타워 = 선택(정보·업그레이드·판매) / 적 스폰 전 미리보기.
- 키 `1` `2` `3`: Frost / Arc / Ember 선택. `U` 업그레이드, `S` 판매, `Space` 다음 웨이브 시작, `Esc` 선택 해제.
- 버튼: 속도 토글, 조기 시작.

## 6. 기술
- 순수 HTML + CSS + Vanilla JS, Canvas 2D. 외부 라이브러리·이미지·음성 없음(사운드만 WebAudio로 합성).
- 파일: index.html, style.css, game.js
