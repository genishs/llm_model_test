# Frostline Defense

순수 HTML + CSS + Vanilla JS(Canvas 2D)로 만든 타워 디펜스 게임. 별도 설치·빌드·서버 없이 **`index.html`을 브라우저로 열면 바로 실행**됩니다. 데스크톱과 모바일(터치) 모두에서 플레이할 수 있습니다.

## 실행 방법
- `index.html` 파일을 더블클릭 또는 브라우저에서 열어주세요.
- 인터넷 연결이나 패키지 설치, 빌드 과정이 필요 없습니다.

## 조작 방법 (데스크톱)
- **클릭**: 빈 셀 = 선택한 타워 설치 / 기존 타워 = 선택(정보·업그레이드·판매)
- **1 / 2 / 3**: Frost Coil / Arc Node / Ember Mortar 선택
- **U**: 업그레이드, **S**: 판매, **Space**: 다음 웨이브 시작, **Esc**: 선택 해제
- 버튼: Speed 배속 토글(x1/x2), Start Wave(조기 시작 보너스 골드)

## 터치 조작 방법 (모바일 / 휴대폰)
휴대폰 화면에 맞춰 캔버스와 패널이 자동으로 축소되고, 버튼·카드가 터치에 적합한 크기로 배치됩니다.

1. **타워 선택**: 사이드 패널의 Build 카드(Frost / Arc / Ember)를 탭하면 설치할 타워 종류가 선택됩니다(선택된 카드는 테두리로 강조).
2. **타워 설치**: 게임 화면(격자)의 **빈 셀을 탭**하면 선택한 타워가 설치됩니다. 경로 위나 이미 타워가 있는 셀은 설치할 수 없습니다.
3. **타워 미리보기**: 셀을 누르면(탭홀드/드리그 전 터치) 해당 칸이 테두리로 표시되고, 설치 가능 셀에는 반투명 사거리 원과 타워 미리보기가 나타납니다.
4. **기존 타워 선택**: 이미 설치된 타워가 있는 셀을 탭하면 아래 Selection 영역에 정보(피해·사거리·DPS·환급금)가 표시됩니다.
5. **업그레이드 / 판매**: 타워를 선택한 뒤 Selection 아래의 **Upgrade** / **Sell** 버튼을 탭합니다.
6. **웨이브 시작**: 상단 HUD의 **Start Wave** 버튼을 탭해 웨이브를 시작합니다(조기 시작 시 보너스 골드).
7. **배속**: 상단의 **Speed x1 / x2** 버튼으로 게임 속도를 조절합니다.

참고: 모바일에서는 키보드 단축키 대신 화면의 버튼과 카드를 사용하면 됩니다. 화면이 좁은 기기에서는 Build 카드·Selection·Log가 캔버스 아래로 세로로 쌓입니다.

## 외부 자료
- 외부 라이브러리, 이미지, 소리 파일은 사용하지 않았습니다. 사운드만 브라우저의 WebAudio API로 실시간 합성합니다.
