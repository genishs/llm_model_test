# Defense Game

Simple browser-based defense game. No installation required - just open index.html in a browser.

## How to Play
- Click to shoot green bullets at red enemies
- Use arrow keys to move the green player
- Health decreases when enemies reach the bottom
- Score increases by 10 for each enemy destroyed

## Controls
- Click: Shoot
- Arrow Keys: Move
- Tap: Shoot
- Swipe: Move

## Files
- index.html: Main game file (open directly in browser)

## Game Rules
Enemies spawn from the top and move downward. Destroy them with bullets to score points. Avoid letting enemies reach the bottom.
