# Bolt Defense - 디펜스 게임

## 게임 소개
공중에 떠오르는 적을 화살로 쏴서 막아내는 캐주얼 디펜스 게임입니다. 적들이 가까워질수록 화살의 발사 간격이 짧아지며, 모든 적을 격파하는 것이 목표입니다.

## 실행 방법
- `index.html`을 웹 브라우저(Chrome, Edge, Firefox 등)에서 더블클릭하면 바로 실행됩니다.
- 별도 설치, 빌드, 서버가 필요 없습니다.

## 조작법
- **마우스**: 조준(마우스 왼쪽 버튼) — 화살 발사. 마우스 커서 방향에 따라 발사 각도가 결정됩니다.
- **키보드**: `스페이스바` — 화살 발사. 마우스 커서 방향을 기준으로 발사합니다.
- **휠**: 조준/스페이스 연타 시 화살 발사 간격을 조절합니다.

## 파일 구성
- `index.html` — 게임 본체 (HTML, CSS, JS 모두 포함된 단일 파일)
- `README.md` — 이 설명서

## 게임 규칙
- 화살이 닿은 적은 즉시 격파됩니다.
- 적의 체력이 늘어날수록 화살의 발사 속도가 느려집니다.
- 모든 적을 격파하면 다음 웨이브로 진행됩니다. 웨이브를 모두 클리어하면 게임 승리.
