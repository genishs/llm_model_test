# Simple LLM Defense

![게임 스크린샷](https://img.shields.io/badge/Game-Type%20Defense-green)
![버전](https://img.shields.io/badge/Version-1.0.0-blue)

웹 브라우저에서 바로 실행되는 AI/코딩 테마의 타워 디펜스 게임입니다.

## 🎮 게임 소개

"Simple LLM Defense"는 코드베이스를 방어하기 위한 디펜스 게임입니다.

- **테마**: AI/코딩 디펜스 - "버그 몬스터"와 "멀웨어 바이러스"를 막아라!
- **장르**: 타워 디펜스
- **플레이 시간**: 5-10분
- **난이도**: 초급~중급

## 🎯 게임 규칙

### 목표
- 10개의 웨이브를 견뎌내어 승리하세요!
- 생명을 모두 잃거나 웨이브를 모두 통과하면 게임 종료

### 방어기 (Tower) 종류

| 이름 | 가격 | 데미지 | 사거리 | 공격 속도 | 특징 |
|------|------|--------|--------|-----------|------|
| 🔥 파이어월 | $50 | 10 | 120px | 60프레임 | 균형 잡힌 성능 |

| 🧪 컴파일러 | $150 | 30 | 180px | 90프레임 | 고데미지 원거리 |

| 🦠 바이러스 | 파랑 | 보통 | 보통 | $15 | 중간 적 |
| 🦠 멀웨어 | 보라 | 느림 | 높음 | $25 | 탱커 |

## 🎮 조작 방법

### 기본 조작
1. **방어기 선택**: 하단 UI에서 원하는 방어기를 클릭
2. **설치**: 맵 위의 빈 공간을 클릭하여 방어기 설치
3. **웨이브 시작**: "웨이브 시작" 버튼 클릭

### 커맨드 목록
- `방어기 선택` → 방어기 버튼 클릭
- `설치` → 맵 클릭 (경로 근처에는 설치 불가)
- `ウェ이브 시작` → 적 등장
- `일시정지` → 게임 멈춤
- `재개` → 게임 재개

### 설치 규칙
- 경로 근처 (40px 이내)에는 설치 불가
- 다른 방어기 근처 (50px 이내)에는 설치 불가
- 돈이 부족하면 설치 불가
